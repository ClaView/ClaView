# 골든셋 초안 5건

- 관리: 팀 공동 / 갱신일: 2026-09-23
- 상태: 개발·검토용 초안. 정답 승인·평가 실행 결과가 아닙니다.
- 출처: 아래 노션 원문을 2026-09-23 확인했습니다. 질문과 기대 행동은 원문을 따르고, 검수 기록과 후속 확인 항목을 보완했습니다.
- 기준: [골든셋과 평가 계획](../../docs/design/골든셋과_평가계획.md)

이 문서는 5건의 질문·기대 행동·판정 기준을 관리하는 기준본입니다. `CV-G001`~`CV-G005`는 이번 정리에서 부여한 관리 ID입니다. 자동 평가용 JSON과 채점 코드는 아직 없으며, 현재 5건 모두 성능 점수 집계 대상이 아닙니다.

별도 [검색 개발 질문 48건](review/검색평가_초안_48건.json)은 받은 원본의 고정 스냅샷입니다. Q01-P는 CV-G001과 질문이 같고, 나머지도 관련 계열이 있으므로 독립 평가셋으로 합산하지 않습니다. [평가 계획의 연결표](../../docs/design/골든셋과_평가계획.md#별도로-작성된-개발-질문과의-관계)를 통해 함께 검토합니다. 이 MD 5건의 자동 채점용 변환본은 아직 없습니다.

## 1. CV-G001 · 명확한 질문

> 2024년 경제심리지수 원계열을 월별로 보여줘.

| 구분 | 내용 |
| --- | --- |
| 질문에 명시된 조건 | 경제심리지수 · 원계열 · 2024년 · 월별 |
| 정답 후보 | `DT_513Y001`의 경제심리지수 원계열 |
| 기대 행동 | 지정한 계열·기간·주기를 유지해 조회 조건 구성 |
| 통과 기준 | 원계열·2024년·월별 조건을 모두 선택 |
| 실패 기준 | 순환변동치 등 다른 계열 선택, 기간·주기 임의 변경 |
| 근거 | 노션의 경제심리지수 검색 문서와 메타정보 관찰 기록 |
| 남은 확인 | 실제 항목·분류 코드, 계열 단위, 요청 유효성, 원표 수치 대조, 다른 팀원 검수 |

보완할 사항: 과거 값이 개정될 수 있으므로 정답 수치를 채울 때 조회 시점과 응답 스냅샷을 함께 고정합니다. 현재 숫자 정답은 미기록입니다.

## 2. CV-G002 · 일상어 연결

> 2024년 예금은행 주담대 신규취급액 기준 금리를 월별로 보여줘.

| 구분 | 내용 |
| --- | --- |
| 질문에 명시된 조건 | 예금은행 · 주담대 · 신규취급액 기준 · 2024년 · 월별 |
| 정답 후보 | `DT_121Y006`의 주택담보대출 계열 |
| 기대 행동 | 주담대를 주택담보대출로 연결하고 지정된 기준 유지 |
| 통과 기준 | 주택담보대출·신규취급액·2024년 월별 조건을 모두 선택 |
| 실패 기준 | 가계대출 전체 선택, 잔액 기준으로 변경 |
| 근거 | 노션의 주담대 매핑 및 신규취급액 기준 대출금리 검색 문서 |
| 남은 확인 | 주택담보대출의 실제 항목·분류 코드, 단위·주석, 요청 유효성, 수치 대조, 다른 팀원 검수 |

주의: 기존 가계대출 조회 사례의 분류 코드를 그대로 사용하지 않습니다. 표 ID가 같아도 주택담보대출과 가계대출 전체는 서로 다른 선택 대상입니다.

## 3. CV-G003 · 모호한 질문과 후속 답변

첫 질문:

> 카드 사용을 보여줘.

평가에 사용할 사용자 후속 답변:

> 2024년 신용카드로 물건이나 서비스를 구매한 금액을 월별로 보여줘.

| 구분 | 내용 |
| --- | --- |
| 첫 질문에서 부족한 조건 | 카드 종류 · 건수/금액 · 기간 · 주기 |
| 첫 응답의 기대 행동 | 필요한 조건을 확인. 질문의 문구 자체는 고정하지 않음 |
| 후속 답변 이후 후보 | `DT_602Y002`의 신용카드 물품·용역 구매 이용 금액, 2024년 월별 |
| 통과 기준 | 필요한 조건을 확인하고 후속 답변의 카드 종류·구매 금액·기간·주기를 반영 |
| 실패 기준 | 카드 종류나 건수/금액을 설명 없이 임의 확정, 금액 요청에 건수 제공, 현금서비스 포함 총액으로 대체 |
| 근거 | 노션의 지급결제통계 검색 문서 및 메타정보 관찰 기록 |
| 남은 확인 | 되묻기 정책 합의, 실제 코드·단위·집계 기준, 요청 유효성, 수치 대조, 다른 팀원 검수 |

이 사례는 우선 조건을 확인하는 경로를 검토합니다. 모든 모호한 질문에 같은 질문 문구나 동일한 기본값을 적용하자는 확정 정책은 아닙니다. 확인 질문을 만들기 위한 후보 검색은 가능하며, 후보 검색과 최종 조회 조건 확정은 구분합니다.

보완할 사항: 첫 응답의 조건 확인과 후속 응답의 계열 선택을 각각 판정합니다. 전체 과업 성공은 두 단계를 모두 충족해야 합니다. 후속 수치 결과까지 평가하려면 수치 정답도 검수해야 합니다. 금액의 집계가 기간 합계인지 일평균인지는 공식 근거 확인 전 단정하지 않습니다.

## 4. CV-G004 · 두 표 비교

> 2024년 예금은행 가계대출 금리를 신규취급액·잔액 기준으로 월별 비교해줘.

| 구분 | 내용 |
| --- | --- |
| 질문에 명시된 조건 | 예금은행 · 가계대출 · 신규취급액과 잔액 비교 · 2024년 · 월별 |
| 필수 후보 1 | `DT_121Y006`의 가계대출 신규취급액 기준 계열 |
| 필수 후보 2 | `DT_121Y015`의 가계대출 잔액 기준 계열 |
| 기대 행동 | 두 계열을 모두 선택하고 동일 월 기준으로 나란히 비교 |
| 통과 기준 | 두 계열·기간·주기가 모두 맞으며 기준 차이를 표시 |
| 실패 기준 | 한 계열 누락, 다른 대출 항목 선택, 두 금리를 합산해 하나의 금리로 표시 |
| 근거 | 노션의 가계대출 비교 문서와 두 표의 메타정보·주석 |
| 남은 확인 | 두 계열 각각의 실제 코드·단위·주석, 요청 유효성, 원표 수치 대조, 다른 팀원 검수 |

보완할 사항: 신규취급액·잔액은 포괄범위가 다를 수 있으므로 해당 주석을 결과에 반영합니다. 차트 종류나 이중축 사용을 정답으로 고정하지 않습니다. 같은 단위와 시점으로 두 기준을 구분해 읽을 수 있는지 확인합니다. 결측 시점이 있다면 숨기거나 값을 만들어 채우지 않도록 처리 기준을 정합니다.

## 5. CV-G005 · 범위 밖 질문

> 삼성전자 주가를 보여줘.

| 구분 | 내용 |
| --- | --- |
| 기대 행동 | 현재 프로젝트의 한국은행 소관 통계표 조회 범위에서 개별 종목 주가를 제공하지 않는다고 안내 |
| 통과 기준 | 지원 범위와 제공할 수 없는 이유 설명 |
| 실패 기준 | 관련 없는 통계표를 정답처럼 제시, 주가 수치 생성 |
| 근거 | 프로젝트에서 정한 조회 범위 |
| 남은 확인 | 범위 판정과 안내 기준에 대한 다른 팀원 검수 |
| 표·항목 코드 및 수치 정답 | 해당 없음 |

대안 제시는 선택 사항입니다. 대안이 원래 요청의 정답인 것처럼 제시하지 않습니다. 이 사례를 승인하기 위해 불필요한 수치 조회를 할 필요는 없습니다.
