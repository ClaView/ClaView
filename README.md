# ClaView

자연어 질문에 맞는 한국은행 소관 통계표를 KOSIS Open API에서 찾아 조회하고, 표·그래프와 출처를 제공하는 프로젝트입니다.

## 1. 목표와 수행 범위

- 대상: **KOSIS Open API 내 한국은행 소관 통계표 전체**. 금리 사례는 구현과 시험에 사용하는 예시입니다.
- 처리: 질문 해석 → 통계표·항목·분류 선택 → 자료 조회·필요한 가공 → 표·그래프·근거 제공.
- 결과물: 에이전트, 외부 클라이언트에서 사용할 MCP 서버, 검수한 평가 사례와 측정 결과.
- 원자료 수치는 API 응답에서 가져오고, 계산한 값에는 가공 방법을 남깁니다.

현재 저장소에는 개발환경, 조사 자료, 설계·평가 초안이 있습니다. 검색·조회·시각화 서비스와 MCP 서버는 아직 구현 전입니다. 자료별 검수 상태는 [데이터 안내](data/README.md)에서 확인할 수 있습니다.

## 시작하기

Python 3.12와 [uv](https://docs.astral.sh/uv/)를 사용합니다. 저장소 루트에서 실행하며, 기본 검사는 API 키가 필요하지 않습니다.

```sh
uv python install 3.12
uv sync --locked
uv run --locked python -m pytest -q
uv run --locked ruff check src tests
uv run --locked ruff format --check src tests
```

설정과 팀원 환경 재현 방법은 [공통 개발환경](docs/guides/공통_개발환경.md)에 있습니다.

## 저장소 구조

| 위치 | 내용 |
| --- | --- |
| `src/` | 프로젝트 기능 코드. 현재는 기본 모듈만 있음 |
| `scripts/` | 자료 검수 등 직접 실행하는 도구 |
| `data/` | 통계표 목록, 메타 현황, 검토용 매핑·검색 문서 |
| `eval/` | 개발 질문·골든셋 초안, 이후 평가 코드와 결과 |
| `tests/` | 키와 외부 연결 없이 실행하는 기본 검사 |
| `docs/guides/` | 설치·API·데이터 작성 절차 |
| `docs/design/` | 개발계획·구조·평가 기준·설계 결정 |
| `docs/research/` | 통계표 조사와 모델 시험 결과 |

`src/claview.py`는 현재 설치되는 기본 모듈입니다. 기능 코드는 구현할 때 `src/`에 추가합니다. 생성한 원자료·색인·로그는 기본적으로 Git에서 제외합니다.

코드와 구현 문서, 재현할 자료는 GitHub에서 관리합니다. 일정·담당·회의 기록은 팀 노션에서 관리하고 관련 GitHub 문서를 연결합니다. 작업 브랜치에서 변경 목적과 확인 결과를 커밋·PR에 적고, 관련 기능을 맡은 팀원이 검토한 뒤 병합합니다. API 키와 개인 자료는 올리지 않습니다.
