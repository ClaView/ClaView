# 한국은행 통계표 메타정보 조사 결과

- 검토일: 2026-09-23 / 관리: 데이터 담당·팀 공동 검수
- 대상: 팀이 제공한 기관 301의 목록·메타 현황·파싱된 메타 캐시
- 확인 방법: 파일별 식별자·응답 상태·집계 대조, 수집 코드의 요약 규칙 검토
- 한계: 이번 검토에서 KOSIS API 재호출·전 표 수치 조회·원표 대조는 하지 않았습니다. 원파일에 수집 시각 필드가 없어 검토일을 API 수집일로 사용하지 않습니다.
- 자료·컬럼 설명: [데이터 안내](../../data/README.md)

## 2. 구조에서 확인한 차이

- 다주기 표는 **196/349개, 약 56.2%**입니다. 연·분기·월을 함께 제공하는 표는 102개입니다.
- 기존 요약 방식으로 분류축 수는 1축 170개, 2축 91개, 3축 87개, 4축 1개입니다. 이 집계는 분류의 `OBJ_NM` 고유 개수이므로 향후 공식 축 ID 기준으로 재확인합니다.
- CSV의 `항목수`는 **ITM 응답 중 `OBJ_ID != "ITEM"`인 행 수**입니다. 범위는 1~927이며, 공통 ITEM 수나 조회 가능한 전체 계열 수가 아닙니다.
- UNIT가 빈 92개 중 39개는 ITM의 단위 필드에서 요약 단위를 얻었고, 나머지 53개는 요약 단위도 공란입니다.
- 53개 모두의 단위가 항목명에서 확인됐다고 단정하지 않습니다. 항목명·주석·원표에 근거가 있는지 추가 검토해야 합니다.
- 한 표에 여러 단위·지수 기준 표기가 존재합니다. 표 전체에 단위 하나를 지정하거나 모든 기준을 자동 통일하지 않습니다.

수록기간은 이 표에서 생략했습니다. 현황 CSV는 월 주기가 있으면 월 기간을 대표값으로 쓰고, 없으면 PRD 첫 행을 사용합니다. 다주기 표의 전체 기간을 대표값 하나로 판단하지 않습니다.

예를 들어 대표 샘플의 `DT_121Y006`에는 다음처럼 기록돼 있습니다.

| 주기 | 시작 | 끝 |
| --- | --- | --- |
| 월 | 1996.01 | 2026.07 |
| 분기 | 1996 1/4 | 2026 2/4 |
| 년 | 1996 | 2025 |

[대표 메타 3표](../../data/samples/한국은행_메타정보_대표3표.json)에는 신규취급액·잔액 금리 표와 3개 분류 축을 가진 예금규모별 계좌수 및 금액 표를 넣었습니다. 이는 캐시에서 추출한 파싱 결과이며, 수치 조회 응답이나 골든셋 정답이 아닙니다.

## 4. 예외 처리와 남은 검증

기존 조사 문서에는 다음 사례가 보고돼 있습니다.

| 표 ID | 보고된 상황 | 이번 확인과 남은 작업 |
| --- | --- | --- |
| DT_111Y004 | PRD 일시 오류 후 재수집 | 최종 캐시 상태는 ok. 최초 실패 응답·재시도 로그는 별도 확인 필요 |
| DT_161Y007 | UNIT 일시 오류 후 재수집 | 최종 상태 확인. 타임아웃과 호출 제한 중 정확한 원인은 로그로 확인 |
| DT_105Y001 | ITM의 잘못된 JSON escape를 보정 | 코드에 비표준 escape 보정 로직 존재. 제공 캐시는 보정 후 객체이므로 원시 HTTP 본문의 오류를 이 파일만으로 재현할 수 없음 |

표 전체의 모든 응답이 규격 위반이라는 뜻은 아닙니다. 보정 로직은 수집 코드 통합 전 원문·적용 패턴·회귀 테스트와 함께 검토합니다.
