## 수집 담당자가 인계할 내용

- 실행 코드·의존성·인증 설정 방법, 키를 제거한 실행 명령
- 목록 스냅샷과 수집 시각, 표별 메타 종류별 성공·빈 응답·오류
- 대표 표의 항목·분류 코드, 주기·수록기간·단위·주석
- 원 응답, 가공 결과, 재시도·파싱 복구 등 예외 처리 기록
- 검수자, 검수 범위, 미확인 사항과 공용 산출물 위치

기록 필드 초안:

```text
org_id / tbl_id / collected_at / metadata_version
메타 종류별 응답 상태 / 항목·분류 / 주기·기간
단위 / 단위 근거 / 주석 / 검수 상태 / 예외 사유
```

응답 성공 → 파싱 성공 → 의미 검증 → 실제 자료 조회 검증을 각각 기록합니다. 단위는 공식 응답·항목 수준 확인·추정을 구분하고, 추정은 `inferred` 등으로 표시해 원표나 자료 응답 대조 전 검증 완료로 올리지 않습니다.

JSON 복구 시 원 응답·복구 패턴·변경 내용·테스트를 기록하고, 확인한 패턴에만 복구 규칙을 적용합니다.

## 용어 매핑 양식

| 항목 | 작성 내용 |
| --- | --- |
| 사용자 표현 | 실제 질문에 들어올 법한 표현 |
| 공식 후보 | 표·항목·분류의 명칭과 코드 |
| 관계 | 동의어 / 관련 개념 / 조건부 연결 |
| 구별 조건 | 신규취급액·잔액, 말잔·평잔, 원계열·계절조정 등 |
| 근거 | 공식 정의·주석·메타 버전 |
| 적용 시점 | 명칭·기준의 적용 기간, 확인일 |
| 확인 질문 | 질문만으로 선택할 수 없을 때 필요한 조건 |
| 검수 상태 | 작성자·검토자·초안/검증됨 |

예를 들어 ‘대출 부담’은 ‘가계대출 금리’의 정확한 동의어가 아닙니다. 부채 규모·원리금 등 여러 개념을 뜻할 수 있으므로 관련 후보와 확인 질문으로 연결합니다. 사전에 없는 표현도 검색할 수 있어야 합니다.

## 검색 문서 구성 초안

```text
표 ID / 기관 / 분류 경로 / 표명
세부 항목·분류 및 코드
통계 기준 / 단위 / 지원 주기 / 수록기간
정의·주석 / 관련 표현 / 적용 시점 / 메타 버전
```

같은 대표 표로 매핑과 검색 문서를 작성합니다. 문서 단위는 입력 크기와 후보 정확도로 결정합니다. 키워드 기준선과 임베딩·하이브리드 방식을 같은 질의로 비교합니다.

표 이름이 같다는 이유로 병합·중복 제거하지 않습니다. 기관·표 ID를 식별 기준으로 두고 목록 경로 차이와 통계 기준을 확인합니다. 검색 결과의 코드는 실제 메타와 대조한 뒤 조회에 사용합니다.
