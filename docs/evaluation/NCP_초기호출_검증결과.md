# NCP 9종 초기 호출 결과와 제한적 평가

- 실행·검토 기준일: 2026-09-22 / 문서 이관·정리일: 2026-09-23
- 관리: API 담당
- 상태: 9종 최소 연결 확인. 정식 모델 비교·전체 검색·E2E 성능 평가 전.
- 근거: 기존 검증 문서에 기록된 결과 JSON 9개, 총 13회 요청. 이번 이관에서 원본 재분석·추가 API 호출은 하지 않았습니다.
- 공유 범위: 입력 요약·측정값·관찰 결과. 실행 코드와 원본 결과 파일은 아직 이 저장소에 포함하지 않았습니다.
- 관련: [모델 분석](../api/NCP_모델분석과_적용방향.md), [API 구조·구현 안내](../api/NCP_API_활용가이드.md), [비용·한도](../api/NCP_비용과_이용한도.md)

## 1. 핵심 결론

- 대화 5종, 임베딩 2종, 리랭커, RAG Reasoning의 작은 요청은 모두 `worked`로 기록되었습니다.
- `worked`는 응답 형식 검사의 통과입니다. 내용 검수에서는 DASH-001의 임의 기준 선택과 리랭커의 입력 밖 안내가 확인되었습니다.
- 이 기록만으로 최종 모델을 선정하지 않습니다. 비교 후보와 선정 기준은 모델 분석 문서에서 관리합니다.
- HCX-007은 JSON 구조화 출력·추론의 이점이 필요한지 별도 시험합니다. 현재 결과는 추론을 끈 대화입니다.
- RAG Reasoning은 첫 도구 제안만 확인했습니다. 검색 실행·결과 재전달·최종 답변·MCP 연동은 미검증입니다.

## 2. 시험 조건과 재현 근거

### 공통 입력

대화 질문: “최근 가계대출 금리 보여줘.”

임베딩 질문: “새로 받은 가계대출의 금리”

대화·리랭커·임베딩에 사용한 설명용 요약:

| ID | 입력 내용 |
| --- | --- |
| DT_121Y006 | 예금은행 대출금리(신규취급액 기준). 계정항목별 분류에서 가계대출 선택. 월별, 연리%. 해당 기간 새로 취급한 대출의 금리를 나타내는 계열. 잔액 기준과 구분해야 한다. |
| DT_121Y015 | 예금은행 대출금리(잔액 기준). 계정항목별 분류에서 가계대출 선택. 월별 금리. 기존 대출을 포함한 대출 잔액의 금리를 나타내는 계열. 신규취급액 기준과 구분해야 한다. |

위 표는 초기 시험의 설명용 메타 입력을 요약한 것입니다. KOSIS 원응답·전체 메타·골든셋이 아닙니다. RAG 첫 요청에는 문서가 아니라 질문과 검색 도구 정의만 보냈습니다.

추가 실행 4개 대화 모델의 요청 본문은 같은 메시지와 temperature=0.1, 출력 예산 512를 사용했습니다. HCX-007은 `maxCompletionTokens`, `thinking.effort=none`; 나머지는 `maxTokens`입니다. v1/v3의 기본 파라미터·토크나이저가 다르고 seed를 고정하지 않아 완전히 통제된 벤치마크는 아닙니다. DASH-002의 앞선 기록에는 요청 본문이 없어 동일 설정을 파일만으로 재검증할 수 없습니다.

## 3. 대화 모델 5종

시간은 각 1회 요청의 클라이언트 관측값이며 평균·p95·SLA가 아닙니다. 출력 길이도 달라 속도 순위로 일반화하지 않습니다.

| 모델 | 입력/출력 토큰 | 관측 시간 | 응답 내용 | 제한적 평가 |
| --- | --- | --- | --- | --- |
| DASH-001 | 192 / 76 | 1.700초 | 신규취급액 표를 바로 안내 | 이 질문에서 기준 확인 지시 미충족 |
| DASH-002 | 226 / 30 | 0.688초 | 신규취급액/잔액 선택 질문 | 기준 확인 충족. 기간 확인은 누락 |
| HCX-003 | 192 / 28 | 1.175초 | 두 기준 중 선택 요청 | 이 질문에서 기준 확인 충족 |
| HCX-005 | 226 / 76 | 1.956초 | 통계 기간과 두 기준을 확인 | 이 질문에서 기준·기간 미확정 식별 |
| HCX-007 | 226 / 34 | 10.825초 | 두 기준에 따라 결과가 다름을 설명 | 기준 확인 충족. 특화 기능·지연 재검증 필요 |

내용 검수 기준: ① 기준을 임의 선택하지 않음 ② 두 기준을 확인함 ③ 기간의 미확정을 짚음 ④ 실제 통계 수치를 만들지 않음. 1건에 대한 관찰이며 일반 정확도 점수를 부여하지 않습니다.

### 판단을 뒷받침하는 실제 응답

**DASH-001**

> 최근 가계대출 금리는 예금은행 대출금리(신규취급액 기준) DT_121Y006 에서 확인할 수 있어.

두 후보가 주어졌지만 한 기준을 먼저 선택했습니다. 표 ID는 입력에 있던 것이므로 새로운 ID를 지어낸 사례는 아닙니다. 문제는 확인 없이 기준을 선택한 점이며, “조회 코드를 생성하지 말라”는 출력 제약과도 맞지 않습니다. 금리 수치 자체를 생성하지는 않았습니다.

**DASH-002**

> 최근 가계대출 금리는 신규취급액 기준으로 보시겠습니까? 아니면 잔액 기준으로 보시겠습니까?

**HCX-003**

> 최근 가계대출 금리를 어떤 기준으로 보길 원하시나요? 신규취급액 기준과 잔액 기준 중 선택해 주세요.

**HCX-005**

> 1. 통계 기간: 몇 개월 전 혹은 몇 년도 자료가 필요한지 확인합니다.
> 2. 기준: '신규취급액'과 '잔액' 중 어떤 것을 의미하는지 확인합니다.

이 사례에서는 확인할 두 축을 제시했습니다. 실제 대화에서는 간결한 질문으로 바꾸고 사용자 답변을 조회 조건에 반영하는지 추가 시험해야 합니다.

**HCX-007**

> 어떤 기준으로 산출된 금리를 원하시나요? 신규취급액 기준이나 잔액 기준에 따라 결과가 달라집니다.

추론을 껐으므로 긴 관측 시간을 “추론 때문에 느렸다”고 설명할 근거는 없습니다. 네트워크·서비스 상태·반복 측정과 특화 기능의 효과를 함께 확인합니다.

## 4. 임베딩 v1/v2

각각 문서 2개와 질문 1개, 3회 호출이며 모두 1024차원 응답을 반환했습니다. v1은 `clir-emb-dolphin`입니다. `clir-sts-dolphin`은 시험하지 않았습니다.

| 항목 | v1 | v2 |
| --- | --- | --- |
| 문서1/문서2/질문 입력 토큰 | 49 / 50 / 11 | 55 / 54 / 8 |
| 요청별 시간 | 0.116 / 0.086 / 0.085초 | 0.130 / 0.098 / 0.086초 |
| 요청 시간 합계 | 0.287초 | 0.314초 |
| 신규취급액 유사도 | 0.985366 | 0.707960 |
| 잔액 유사도 | 0.984114 | 0.669981 |
| 1위 후보 | 신규취급액 | 신규취급액 |

두 모델 모두 이 질문에서 기대 후보를 위에 두었습니다. 그러나 모델별 점수 분포가 다르므로 0.985가 0.708보다 성능이 좋다는 뜻은 아닙니다. 점수 간격도 모델 간 우열 판단에 쓰지 않습니다.

검색 정확도 우위는 미검증입니다. 유사도는 정답 확률이나 매핑 신뢰도로 보정된 값이 아닙니다. 공식 입력 한도는 v1 500토큰, v2 8192토큰이며 모델별로 동일한 문서 단위와 검수 질문을 사용한 비교가 필요합니다. [v1](https://api.ncloud-docs.com/docs/clovastudio-embedding), [v2](https://api.ncloud-docs.com/docs/clovastudio-embeddingv2)

## 5. 리랭커

- 1회, 2.892초, 입력 133 / 출력 124토큰.
- 두 입력 문서 ID를 인용하고 실제 금리 수치가 없다는 점을 안내했습니다.
- 문서별 순위·점수 목록은 반환하지 않았습니다.
- 다음 문장은 입력 메타에 없는 안내입니다.

> 이러한 정보는 금융감독원이나 한국은행의 공식 웹사이트에서 확인할 수 있습니다.

이 문장의 사실 여부를 이번 시험에서 검증한 것은 아닙니다. 입력 근거 밖의 안내를 덧붙였고, ClaView의 KOSIS 한정 조회 흐름을 직접 따르지 않았다는 점을 문제로 기록합니다. 수치 환각 사례라고 부르지는 않습니다.

**판정:** 후보 문서 기반 답변 생성은 확인했으나, 검색 후보 재정렬의 대체품으로 바로 채택하지 않습니다. 입력 밖 주장·인용 ID·인용 내용 검수 후 사용 여부를 결정합니다. [공식 반환 구조](https://api.ncloud-docs.com/docs/clovastudio-reranker)

## 6. RAG Reasoning

- 1회, 2.006초, 입력 73 / 출력 76토큰.
- 도구 제안: `search_tables({"query": "최근 가계대출 금리"})`.
- 도구 호출 ID 반환, `tool_executed: false`.
- `toolChoice`로 검색 도구를 강제 지정한 시험입니다.
- 종료 사유는 저장 요약에서 null이며, 도구 제안·호출 ID 검사를 통과했습니다. null만으로 오류라고 해석하지 않습니다.

**판정:** 해당 API 접근과 첫 도구 제안 형식을 확인했습니다. 자율적 도구 선택·실제 검색·근거 기반 최종 응답·MCP 연동 성공의 증거는 아닙니다. 검색 결과를 같은 호출 ID로 재전달하는 후속 시험이 필요합니다. [공식 2단계 흐름](https://api.ncloud-docs.com/docs/clovastudio-ragreasoning)

## 7. 이번 기록으로 판단할 수 없는 항목

- 실제 메타 전체를 대상으로 한 검색 정확도와 컨텍스트 크기.
- 개발 질의셋의 조건 선택·필요 확인·불필요 확인 비율.
- 007 구조화 출력·추론, 대화 모델 Function calling의 실제 동작.
- RAG 검색 결과 재전달과 근거 기반 최종 응답.
- 반복 요청의 지연 분포, 동시 호출 한도, 실제 계정 청구액.

추가 시험에서는 이전 두 기록의 누락된 요청 설정을 보완하고 같은 코드·메타·질문을 사용합니다. 현재 저장소에는 시험 CLI와 운영용 클라이언트가 없습니다. 다중 도구, 사용자 답변 상태, 재시도·스트리밍·rate-limit 헤더·실패 사용량 보존은 후속 구현·검증 대상입니다.

모델 비교 후보·선정 조건은 [모델 적용 방향](../api/NCP_모델분석과_적용방향.md), 요청 구조와 후속 구현은 [API 가이드](../api/NCP_API_활용가이드.md)에서 관리합니다. 채택 검토 항목과 결정 기록 방식은 [설계결정과 검토사항](../decisions/설계결정과_검토사항.md)에 정리했습니다. 최종 채택은 미확정입니다. 이 문서는 과거 시험 요약이며, 현재 저장소만으로 동일 실행을 재현할 수 있다는 뜻은 아닙니다.
