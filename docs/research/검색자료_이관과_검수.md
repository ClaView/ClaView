제공 README의 개인 경로와 실제 파일명과 맞지 않는 링크는 옮기지 않았습니다. 장문 설명은 이 문서와 검색·매핑 가이드에 통합하고, 원본 PowerShell 검사와 작성자의 검사 결과는 현재 저장소의 실행 결과로 승계하지 않았습니다.

재확인 명령(저장소 루트, 키·외부 연결 불필요):


이 검사는 동결된 초안의 구조·참조·검수 상태를 확인하며 사전의 의미나 정답을 승인하지 않습니다. 실제 값 검수·검색 실험과 구분합니다. 기준 스냅샷을 교체할 경우 검사와 문서·해시도 함께 검토합니다.

## 3. 의미·설계 검토가 필요한 부분

| 항목 | 확인한 문제 | 반영 방향 |
| --- | --- | --- |
| M004 등 관련 개념 | scope와 실제로 찾아야 할 지표가 다를 수 있음 | 적용 문맥·근거 표와 조회 대상 표를 구분 |
| Q01-A 확인 질문 | 지표가 모호한데 경제심리지수 내부 기준만 질문 | 실제 후보 지표 차이부터 확인 |
| negative 16건 | 다른 유효 계열 탐색·잘못된 대체 방지·개인 자료 요청 등이 섞임 | 모두 범위 밖/자료 없음으로 채점하지 않음 |
| 상세 메타 | 항목·분류 코드 null, 화면 일부 항목만 관찰 | 조회 계획으로 바로 변환하지 않고 원본 메타와 연결 |
| 두 매핑 자료 | 후보 CSV는 생성·유사도 기록, JSON은 관계·조건 초안 | 서로 덮어쓰지 않고 표현·공식 개념·적용 범위별로 비교 |
| 역방향 순위 | 팀원이 방향 변경을 제안했으나 비교 결과 CSV·코드·대상 집합 미확보 | 검토 제안으로만 유지, 자동 승인·성능 개선 확정 금지 |

349개 기본 문서를 확보한 것과 전체 계열의 상세 설명·API 조회 가능성을 검증한 것은 다릅니다. 구조 검사 통과를 검색 정확도 100%로 표현하지 않습니다.
