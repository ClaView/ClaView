## 이력과 설계 자료

날짜가 붙은 기존 계획·측정·파트 설계와 NCP·HCX 연구 문서는 당시 구현과 비교 근거다. 과거 점수·명령·모델을 현재 동작으로 읽지 않는다. 현행 구조는 위 문서와 코드가 기준이며, 과거 기록의 사실은 소급해서 고치지 않는다.
