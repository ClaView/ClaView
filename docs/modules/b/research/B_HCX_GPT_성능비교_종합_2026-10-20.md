# ClaView B단계 모델 성능 비교 (HCX-007 vs gpt-6.1-sol)

- 작성일: 2026-10-20
- 범위
  - 정확도: 기존 골든 22건 + 신규 9건(CV-NEW-07 제외), 케이스당 3회 반복, 총 93회
  - 지연시간·비용: 기존 골든 22건 × 3회(66호출). 신규 질문은 미측정

---

## 1. 결론

**정확도·안정성 기준으로는 gpt-6.1-sol이, 호출당 비용 기준으로는 HCX-007이 유리함. 응답 속도는 평균 기준으로 동일 수준임.**

### 1.1 기준별 비교

| 기준 | gpt-6.1-sol | HCX-007 | 우세 |
|---|---|---|---|
| 최종 통과율 (93회) | 93/93 | 90/93 | GPT (소폭) |
| 모델 원본 정확도 (보정 없이 통과) | 93/93 (100%) | 60/93 (64.5%) | GPT (큰 차이) |
| 신규 질문 (튜닝에 미사용) | 27/27 | 24/27 | GPT |
| 실제 모델 오류 | 0건 | 3건 (CV-NEW-10) + 비결정 오류 1건 | GPT |
| 프로그램 보정 의존도 | 없음 | 높음 | GPT |
| 실행 간 재현성 (22건 2회 실행) | 132/132, 편차 없음 | 131/132, 실행마다 상이 | GPT |
| 응답시간 평균 (22건) | 3.16초 | 3.23초 | 동일 |
| 응답시간 p95 (22건) | 4.57초 | 6.46초 | GPT |
| 호출당 비용 (22건 평균) | 18.31원 | 8.49원 | HCX (약 2.2배 저렴) |

### 1.2 근거

- 보정 없이도 정답 산출: HCX-007은 통과 건의 약 1/3이 이름 교정·확장 가드로 통과함. GPT는 가드 개입이 0건임.
- 튜닝 편향 하에서도 우세: 기존 22건은 HCX 기준으로 규칙을 다듬은 세트이나, GPT가 동일 프롬프트에서 보정 없이 전 케이스를 통과함.
- 신규 질문에서 HCX 실제 오류 확인: CV-NEW-10에서 예금취급기관 대신 예금은행 계열을 선택하였고, 3회 모두 동일하며 가드로 구제되지 않음.
- 재현성: HCX는 temperature 0·seed 42임에도 22건 재실행에서 결과가 달라짐(CV-AB-03에서 30106 추가 선택). GPT는 temperature 기본값(1)임에도 결과가 동일함.
- 응답시간: 평균은 같으나 HCX는 시리즈가 많은 답(출력 토큰이 큰 답)에서 지연이 커져 p95가 GPT보다 길음.
- 비용: 입력 토큰이 비용을 좌우하며, GPT 단가(입력 2,655.82원 / 출력 13,279.10원, 100만 토큰당)가 HCX(입력 1,250원 / 출력 5,000원)보다 높아 호출당 약 2.2배임. 다만 호출당 절대 금액은 20원 안팎으로 작음.

### 1.3 판단 보류 사항

- 신규 질문의 지연시간·비용은 측정하지 않았음. 22건 기준 값을 일반화할 때는 입력 크기 분포 차이를 감안해야 함.
- GPT는 reasoning low를 설정했으나 추론 토큰이 0으로 기록되어 실질적으로 추론이 사용되지 않음. 추론 사용에 따른 영향은 낮은 것으로 보이나, 추론 강도 상향(medium)에 따른 정확도·비용 변화는 미확인임.
- 신규 정답은 작성자(Claude)가 도출하였고 팀 확인 전임. CV-NEW-10은 "예금취급기관" 해석에 의존함.
- 표본 규모가 작고(신규 9건 × 3회, 지연시간 66호출 1회) 시간대·서버 부하의 영향을 받음.

### 1.4 제안

- 정확도·안정성을 우선하면 GPT를 B파트 1순위 후보로 하고, 이름 교정·확장 가드는 안전망으로 유지함. (규칙 자체의 문제는 모델과 무관하게 잔존함)
- 비용을 우선하면 HCX-007을 유지하되, 규칙 보정 의존도·실행 간 편차·유사 이름 계층 혼동 오류를 감수하고 가드를 강화해야 함.
- 선택 기준은 요구 정확도와 단가 중 무엇을 우선하느냐이며, 정확도 확보에 드는 추가 비용은 호출당 약 9.8원(18.31원 − 8.49원)임.
- 확정 전 확인 사항
  - 신규 정답(CV-NEW-03, 04, 10)의 팀 확인
  - 신규 질문 세트의 지연시간·비용 측정
  - GPT 추론 강도(medium) 비교
  - 유사 이름·계층이 겹치는 질문 추가 시험

## 2. 시험 개요

### 2.1 데이터셋·판정

| 구분 | 파일 | 케이스 수 |
|---|---|---|
| 기존 골든 | `eval/cases/golden_set_v1.json` | 22건 (HCX 튜닝에 사용) |
| 신규 질문 | `eval/cases/golden_set_v2_new10.json` | 9건 (CV-NEW-07 제외, 팀 확정 전) |

- 입력: 골든의 A단계 결과. B단계만 실제 모델로 실행함.
- 판정: 선택 시리즈 집합이 골든과 일치하면 통과함.
- CV-NEW-07은 이름 교정 규칙 보완 대상으로 분리하여 전체 집계에서 제외함.
- 보정 구분: 모델 원본이 정답이면 "보정 없는 통과", 이름 교정(`named_value`) 또는 확장 가드(`expand_on_leaf`·`expand_promoted`·`expand_named`) 개입 후 정답이면 "보정 후 통과"로 분류함.

### 2.2 실행 조건

| 항목 | HCX-007 | gpt-6.1-sol |
|---|---|---|
| 추론 | thinking: none | reasoning_effort: low |
| temperature / seed | 0 / 42 | 기본값(1) / 미지정 |
| 최대 출력 토큰 | 6,144 | 6,144 |
| 출력 형식 | JSON 스키마 | strict JSON 스키마 |
| 호출 간격 | 12초 | 1초 |

- 프롬프트·입력·판정·프로그램 규칙은 동일함.
- gpt-6.1-sol은 API 제약으로 reasoning_effort 'none', temperature 0을 지원하지 않아 위와 같이 설정함.
- 호출 간격은 속도 제한 대응용이며, 응답시간 측정에는 포함하지 않음.

## 4. 지연시간·비용 결과 (기존 22건 × 3회, 66호출)

### 4.1 측정 기준

- 응답시간: 요청 전송 시점부터 응답 수신 시점까지(마지막 HTTP 시도 기준). `--delay` 대기와 429 재시도 대기는 제외함. 따라서 내부 재시도가 있었던 HCX 8호출의 실제 체감 지연은 표의 값보다 김.
- 비용: 응답에 보고된 입력·출력 토큰에 100만 토큰당 단가를 적용함. 모두 VAT 별도, 원화 기준임.

| 모델 | 입력 단가 (100만 토큰당) | 출력 단가 (100만 토큰당) | 근거 |
|---|---|---|---|
| HCX-007 | 1,250원 | 5,000원 | NAVER Cloud CLOVA Studio 요금 페이지 (1,000 토큰당 1.25원 / 5원) |
| gpt-6.1-sol | 2,655.82원 | 13,279.10원 | 1,000 토큰당 2.65582원 / 13.27910원 (1 USD = 1,327.91원 환산, 달러 기준 $2.00 / $10.00) |

### 4.2 결과

|---|---|---|
| 측정 호출 | 66 | 66 |
| 응답시간 평균 | 3.16초 | 3.23초 |

| 응답시간 p95 | 4.57초 | 6.46초 |
| 응답시간 최대 | 5.21초 | 6.84초 |

- 질문 1건당 B단계 모델 호출은 1회이므로 질문당 비용은 호출당 비용과 같음.

### 4.3 응답시간 해석

- 응답시간은 출력 토큰 수에 거의 비례함(상관계수 GPT 0.86, HCX 0.92).

| 모델 | 회귀식 (응답시간 ≈ 고정 지연 + 출력 토큰 × 계수) |
|---|---|
| gpt-6.1-sol | 약 1.9초 + 토큰당 12ms |
| HCX-007 | 약 1.1초 + 토큰당 15ms |

- HCX는 고정 지연이 짧아 단답에서 빠르고, 시리즈가 많은 답에서 느려짐. CV-AB-04·05(시리즈 5개)에서 HCX는 출력 361~379 토큰에 약 6.5초, GPT는 229~237 토큰에 약 4.6~5.0초가 소요됨.
- 동일한 답에 대해 HCX의 출력 토큰이 GPT보다 약 43% 많음.
- 케이스별 평균은 HCX가 22건 중 13건에서 더 짧음. 평균 기준으로는 두 모델이 동일 수준임.

### 4.4 비용 해석

- 비용은 입력 토큰이 좌우함. 입력이 1.5만 토큰을 넘는 CV-AB-12·20은 호출당 GPT 약 45~47원, HCX 약 20~22원임.
- 22건 평균 호출 규모를 실제 질문에 적용하는 단순 환산(질문당 B단계 호출 1회 가정, 입력 크기 분포가 동일하다고 가정, VAT 별도)

| 질문 수 | gpt-6.1-sol | HCX-007 | 차이 |
|---|---|---|---|
| 1만 건 | 약 18.3만원 | 약 8.5만원 | 약 9.8만원 |
| 10만 건 | 약 183만원 | 약 85만원 | 약 98만원 |

- 실제 비용은 질문의 표 크기 분포에 따라 달라지므로 참고용으로만 사용해야 함.

## 5. 한계

1. 실행 설정이 동일하지 않음. (추론 사용 여부, temperature·seed) GPT는 추론 토큰이 0으로 기록되어 영향은 작을 것으로 보이나 미검증임.
2. 기존 22건은 HCX 튜닝 세트로, HCX에 유리하게 편향될 수 있음.
3. 신규 정답은 팀 확정 전이며, 특히 CV-NEW-03, 04, 10은 해석 의존도가 높음.
4. 표본이 작음(신규 9건 × 3회, 지연시간 66호출 1회). p95는 상위 4건 내외에 좌우되어 변동 가능성이 큼.
5. 응답시간은 시간대·서버 부하의 영향을 받으며, 두 모델을 번갈아 실행하지 않고 각각 실행함.
6. 단가는 목록가 기준이며 GPT는 환율(1,327.91원)을 적용한 환산값임. 환율·세금 처리 방식이 달라 두 모델의 비용 비교는 규모 비교로 해석해야 함.
7. 신규 질문 세트의 지연시간·비용은 측정하지 않음.
8. CV-AB-20 골든 변경분은 팀 확인이 남아 있음.

## 6. 후속 과제

- 신규 정답(CV-NEW-03, 04, 10) 팀 확인
- 신규 질문 세트(신규 9건) 지연시간·비용 측정
- 두 모델을 번갈아 실행하는 방식의 지연시간 재측정
- 추론 설정별 비교 (GPT low/medium, HCX thinking 설정)로 추론 영향 분리
- HCX 내부 재시도 원인 확인(응답 코드 기록 추가)
