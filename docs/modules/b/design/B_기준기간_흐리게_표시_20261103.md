# 계산용 기준 기간 흐리게 표시 (2026-11-03)

- 대상: 연결 `pipeline/claview_pipeline/staged.py`(`ui_cases`, `baseline_block`), 화면 `frontend/src/service_ux.js`. A·B·C 계약과 C 코드는 바꾸지 않음. 화면 카드에 선택 필드 `baseline` 하나만 더함.
- 배경: `2024년 전년 대비`처럼 계산용으로 앞 구간(2023년)을 조회하면 화면에는 요청 기간(2024년)만 보이고 기준 연도는 숨겨졌음. 기준과 함께 보고 싶다는 결정에 따라 차트에 흐리게 보이도록 함.

## 1. 변경

- 카드에 선택 필드 `baseline`을 추가함: `{periods, labels, values{series_id: [값…]}}`. 표시 기간 앞쪽의 조회 시점만 싣고, 값이 하나도 없으면 싣지 않음.
- 카드의 `periods`·`labels`·`series[].values`·`start`·`end`는 요청 기간 그대로임. 따라서 표, CSV, 품질 집계, 가로 막대의 시점 선택은 바뀌지 않음.
- 차트(선·막대·항목별 나눠 보기)는 앞쪽에 기준 시점을 더해 그림. 기준 구간은 점선·옅은 색, 옅은 음영과 `비교 기준` 표시를 씀. 말풍선 날짜에 `(비교 기준)`이 붙음. 저장 PNG에도 같이 들어감.
- 화면 요약의 기간 안내에서 `(화면에는 표시하지 않음)`을 `(차트에 흐리게 표시, 표·내려받기 파일에는 넣지 않음)`으로 바꿈(`baseline`이 있을 때만).
- 차트 그리기는 템플릿을 고치지 않고 `service_ux.js`에서 차트 생성 어댑터를 감싸 처리함(`CV.createResult`에서 카드별 기준 구간을 등록).
- C는 기준 시점을 그대로 포함한 그룹 시점과 점을 이미 넘기고 있어 C 변경이 없음. 기본 보기 선택은 요청 기간 시점 수로 하는 기존 규칙을 유지함.

## 2. 확인

- `pipeline/tests/staged/test_screen_baseline_faded_1103.py` 3건: 기준 연도 12개 시점이 `baseline`으로 분리되고 카드 값은 12개 그대로, 계산 요구가 없으면 `baseline`이 없음, 값이 없으면 싣지 않음. `pipeline` 221건 통과.
- 헤드리스 브라우저(합성 자료): 선그래프 24개 시점 중 앞 12개 점선·음영, 묶음막대 구간 적용, 수치표 12행 유지, PNG 저장 정상, 말풍선 `2023년 3월 (비교 기준)`, 페이지 오류 없음.

## 3. 알아둘 점

- 증감률 계산 자체는 하지 않음(C가 계산하지 않는 기존 안내문 유지). 기준 연도를 함께 보여 줄 뿐임.
- 요청 기간이 한 시점뿐인 경우도 기준 구간이 앞에 흐리게 붙음. 가로 막대 보기는 기준 구간 없이 요청 시점만 선택함.
