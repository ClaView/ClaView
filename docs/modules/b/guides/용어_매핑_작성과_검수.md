# 용어 매핑 작성과 검수

> **2026-10-23(계획 26) 안내**: 이 문서가 부르는 준비 스크립트(`scripts/prepare_mapping_dictionary.py`, `scripts/prepare_a1_mapping_review.py`)는 옛 A 모듈을 import해서 옛 A와 함께 저장소에서 지웠다. 같은 파일이 원격 이력(`b172d75`, `origin/integrated-router-20261022`)과 원본 작업 폴더(B b-1020 사본 등)에 남아 있다. 지금 저장소에서는 아래 재생성 절차를 실행할 수 없고, 이미 만든 자료(`data/` 아래)는 그대로 쓴다. 재생성이 필요하면 옛 A 의존을 걷어 낸 도구를 새로 만든다.

실행 기준은 [runtime/search_mappings.json](../../../data/mappings/runtime/search_mappings.json)과 [Schema](../../../data/mappings/runtime/schema.json)입니다. 79건 모두 draft, 운영 승인0건입니다. approved 정책은 미승인 표현을 운영 확장으로 사용하지 않습니다.

`MappingDictionary`는 적용 조건·제외 조건·범위·공식 근거·검수 상태를 검사합니다. 조건 목록 내부는 OR, 여러 조건은 AND입니다. 충돌·근거 누락·조건 불명은 보류합니다. 동의어와 관련 개념을 구분하며 원문에 없는 명목·실질·잔액·신규취급액을 임의 확정하지 않습니다.

검수자는 표현 의미, 공식 항목 경로, 적용 범위, 실제 인용과 판본을 확인합니다. 실제 사람의 검수만 승인으로 기록합니다. 모델 제안은 draft이며 검수된 기준본을 생성기 결과로 덮어쓰지 않습니다.

별도 [A1 실험](../../../data/mappings/experiments/a1_source_checked_v1/README.md)은 공백 표기8건과 GDP/GNI 2건의 기계적 공식 문자열 확인입니다. 사람 의미 검수·운영 승인과 다릅니다. `--a1-mapping-review`를 명시할 때만 적용하고 기존22의 순위 개선은 확인하지 못했습니다.

```powershell
$mappingRun = "runs/mapping-review-$(Get-Date -Format 'yyyyMMdd-HHmmss')"
uv run --env-file .env --locked python scripts/prepare_mapping_dictionary.py --output "$mappingRun/dictionary"
uv run --env-file .env --locked python scripts/prepare_a1_mapping_review.py --output "$mappingRun/a1-review"
```

원문 검색은 유지합니다. 검증한 표현으로만 보조 검색을 하며 미검수 해석·메타 누락으로 원문 후보를 강제 제외하지 않습니다. [데이터 안내](../../../data/README.md)를 함께 봅니다.
