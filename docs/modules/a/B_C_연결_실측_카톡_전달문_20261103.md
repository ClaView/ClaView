# B·C 담당 카톡 전달문

아래 문구를 그대로 공유할 수 있습니다.

---

현재 버전으로 12문항을 A→B→KOSIS→C까지 실제 확인했습니다. A 최종 표·기간·주기는 기대와 같았고, 조회된 23계열·428개 값도 원응답부터 화면 전달값까지 일치했습니다. 다만 연결 쪽 두 가지를 보완해야 합니다.

**B 담당 확인 부탁드립니다.**

1. 기간 없는 질문에 A가 되물어 `2024년 월별`을 확정하고 `period_source=user_answer`로 정상 전달했습니다. 그런데 B 모델 요청에는 `resolved_period:null`만 들어가 모델이 빈 selection을 반환했습니다. B가 받은 사용자 확정 기간을 **계열 선택 모델 요청에도 제공**하고, 기존 코드의 적용·검증은 유지해 주세요.
2. `전년 동월 대비 증감률` 요청은 비교용 전년도 구간이 빠졌습니다. 표시 기간은 그대로 두고, 필요한 비교 구간을 `calculation_extra`로 구분해 조회하도록 확인해 주세요.

**C·연결·화면 담당 확인 부탁드립니다.**

현재 C는 이 M2 증감률 계산을 지원하지 않아 원자료만 보여 주는데 상위 상태는 `ok`입니다. 계산 지원 범위를 정하고, 미지원이면 **“원자료 조회 완료 · 요청 계산 미완료”**가 요약·화면·저장 기록에 분명히 남도록 맞춰 주세요. 이미 공표된 증감률 표시와 C가 직접 계산한 결과는 구분하면 됩니다.

A에서는 서로 다른 표의 기간이 다르다는 이유로 전달을 막던 부분 하나를 보완했고, 오프라인 확인까지 마쳤습니다. 기간 조건과 표별 문맥을 받는 B에만 전달하며 구형 B는 계속 막습니다. 같은 표의 조건 충돌·불연속 기간·판본 분할·사용자 답 미적용 보호는 유지합니다. 저장 12문항 중 11건은 그대로이고, 해당 차단 문항만 저장 A+합성 B/KOSIS로 연결이 풀렸습니다. 제품 화면에서도 저장 기록 7개 상태를 불러와 표별 차트·기간 안내·대기 상태를 확인했습니다. 답 적용은 저장 응답 재생에서 확인했고, 브라우저에서 새 질문·답 전송은 하지 않았습니다. 추가 실호출 결과는 아닙니다.

focus에서 단위/기준연도 문구가 빠진 3건은 별도 기록했습니다. 이번 실제 메타·조회 결과는 조건을 충족했지만, 그 사실과 focus 생략을 같은 것으로 처리하지 않겠습니다.

우선 저장 응답·가짜 전송으로 수정과 연결을 확인하고 실제 화면까지 재확인한 뒤, 추가 실호출이 필요한 부분만 따로 정하면 좋겠습니다. 구체적인 재현·코드 위치·완료 기준은 **[B·C 연결 실측 보완 요청](B_C_연결_실측_보완요청_20261103.md)**에 정리했습니다.
