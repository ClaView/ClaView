# ClaView 팀 공유본

> 이 문서는 팀 C 공유 ZIP(옛 구조, `c_practice/`) 사용 안내를 그대로 보관한 것이다. 지금 레포에서 화면은 `frontend/`(빌드 `frontend/build/ui_build.py`)와 pipeline API이고, 실행은 [README](../../../README.md) 2절(Docker)을 따른다. ZIP 실행 파일은 `research/c/team_bundle/`, 옛 로컬 서버는 `research/c/legacy_web/`에 보관했다.

## 처음 실행하는 방법 (Windows)

1. ZIP을 다운로드하고 **압축을 전부 풀어 주세요.** ZIP 안에서 바로 실행하지 마세요.
2. Python **3.12**를 설치하세요. 설치 화면의 `Add python.exe to PATH`를 체크하세요. 이미 설치되어 있으면 생략합니다.
3. `01_install.cmd`를 더블클릭하세요. 처음 한 번만 필요합니다. 인터넷으로 필요한 Python 패키지를 내려받습니다.
4. 설치 완료 후 `02_start.cmd`를 더블클릭하세요. HCX 키와 KOSIS 키를 요청하면 **본인이 사용할 키**를 입력하세요. 입력한 문자가 안 보이는 것은 정상입니다.
5. 브라우저가 열리면 질문을 입력하고 `실행`을 누르세요. 예시 질문은 입력만 하며 자동 실행하지 않습니다.

화면 주소: http://127.0.0.1:8775/ (각자 자신의 PC에서만 열리는 주소)

실행 준비가 끝난 뒤 실행 창을 닫아도 서버는 백그라운드에서 유지됩니다. 종료하려면 `03_stop.cmd`를 더블클릭하세요. PC를 껐다 켜면 `02_start.cmd`로 다시 켭니다. 자동 시작은 이 공유본 설치 과정에서 설정하지 않습니다.

## 무엇이 들어 있나요?

- 질문 입력 → A의 표 선택 → B의 항목·기간 해석 → KOSIS 조회 → C의 Highcharts 화면을 실행하는 코드
- 현재 서비스와 같은 A/B 판본, 349개 표 카탈로그·메타정보, 골든셋 22개 예시
- 04·08·13번 실제 조회 저장 샘플과 13번 결측 **합성 시험** 자료
- 기존 Highcharts 시안과 화면 생성에 필요한 JavaScript·CSS

**API 키, 작성자의 실행 이력·질문 로그, 가상환경은 들어 있지 않습니다.** 키를 HTML이나 코드에 적지 마세요. 기본 실행에서는 키를 평문 파일로 저장하지 않습니다. 팀원별 키 또는 사용 승인을 받은 팀 키가 필요합니다. 키의 요금·호출 한도는 사용 계정에 적용됩니다.

## 실행 화면 이해하기

1. 질문 이해: 질문의 대상과 조건을 정리합니다.
2. 통계표 선택: 자동 확정이 어려우면 후보를 직접 확인합니다.
3. 조회 조건 확정: B가 항목·기간을 정합니다. 추가 확인이 필요하면 화면에서 수정합니다.
4. 데이터 조회: KOSIS에서 값을 가져옵니다.
5. 그래프 표시: 여러 항목을 함께 비교합니다. 그래프 종류·항목·기간을 바꿀 수 있습니다.

이 공유본은 현재 서비스 판본을 복사한 것으로, 별도 사전 비교 실험의 개선 코드는 적용하지 않았습니다. 현재 A 골든셋 기준 03번은 자동 진행하고 나머지는 후보 확인이 필요할 수 있습니다. 자동 선택 수가 최종 정답률을 뜻하지는 않습니다. 모든 새로운 질문이 지원된다는 의미도 아닙니다.

## 키 없이 화면만 보려면

`c_practice/abc_integration/dist/sample.html`을 크롬·엣지로 여세요. 저장 샘플을 확인하는 화면이며, 실제 새 질문 실행이나 새 KOSIS 조회는 하지 않습니다. `dist/index.html`을 파일로 열어서는 실제 질문을 실행할 수 없습니다. 실제 실행은 반드시 `02_start.cmd`를 이용하세요.

## 문제가 생기면

- Python을 찾지 못함: Python 3.12를 설치하고 다시 실행하세요.
- 설치 오류: 인터넷 연결을 확인하고 `01_install.cmd`를 다시 실행하세요. 사내 프록시 정책은 관리자 확인이 필요할 수 있습니다.
- 8775번 포트 사용 중: 기존 ClaView 서버가 켜져 있는지 확인하세요. 다른 버전을 이미 켰다면 그 버전의 중지 파일로 종료한 후 실행하세요. 임의의 다른 프로세스는 종료하지 마세요.
- 분석 모델 호출 한도: HCX 사용 한도 문제입니다. 잠시 기다린 뒤 재실행하거나 계정 한도를 확인하세요. KOSIS 장애와는 다릅니다.
- 키 오류: 해당 키의 권한과 유효기간을 확인하세요. 키를 포함한 화면·로그를 채팅에 올리지 마세요.
- 설치 확인: `04_check.cmd`를 실행하세요. **외부 호출 없이** A 22건·저장 샘플·로컬 HTTP를 점검합니다. 실제 HCX/KOSIS 통과를 보장하는 검사는 아닙니다.

직접 터미널에서 실행하려면 공유본 최상위 폴더에서:

```powershell
py -3.12 -X utf8 setup_team.py
.\.venv\Scripts\python.exe -X utf8 team_check.py
```

## 공유 시 주의

사용 후 생성되는 `.runtime`, `runs`, 브라우저의 조회 이력, `.venv`는 재공유하지 마세요. 이 ZIP 원본을 공유하면 됩니다. 다른 사람에게 질문 실행을 웹 링크로 공개하는 배포본이 아니라, 각자 PC에 설치하는 개발·시연용 공유본입니다. Highcharts 등 외부 구성요소의 이용 조건은 `THIRD_PARTY_NOTICES.md`를 확인하세요.
