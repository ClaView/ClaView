# 공유본 검수 결과 (2026-10-22)

## 확인한 내용

- ZIP을 별도 폴더(공백 포함 경로)에 압축 해제하고 Python 3.12의 새 가상환경에 requirements.txt 의존성을 설치했습니다. 작성자의 기존 가상환경은 복사하지 않았습니다.
- 공유본 경로의 A/B/C 모듈을 가져오는지 검사했고, A와 B의 카탈로그·원본 메타정보 해시 일치를 확인했습니다.
- 현재 서비스와 같은 A 코드로 골든셋 22건을 실행했습니다. 자동 확정 1건(03), 확인 필요 21건입니다. 사전 비교 화면의 실험 코드를 서비스에 몰래 반영하지 않았습니다.
- 실제 A 후보 선택 후 **모의 B·모의 fetch**를 사용해 저장된 04번 결과가 C에 전달되고, 5개 계열이 한 카드에 표시되는 연결 계약을 확인했습니다.
- 저장된 04·08·13·13결측 샘플을 C로 변환해 값이 유지되는지 확인했습니다.
- 합성 시험으로 정상적인 0과 자료 없음이 구분되고, 결측 구간을 선으로 이어 붙이지 않는지 확인했습니다.
- 별도 로컬 HTTP 서버에서 질문 화면·서버 정보·저장 샘플 화면의 응답을 확인했습니다.
- 새 환경에서 설치 스크립트의 끝까지 실행을 확인했습니다. 브라우저에서 예시 선택은 입력만 되고, 실행을 누르면 실제 A가 후보 확인 화면을 보여주는 것을 확인했습니다.
- 브라우저의 저장 샘플 화면에서 04번 5계열, 08번 14계열, 13번 3계열의 Highcharts 표시와 합성 결측 안내를 확인했습니다. 새 B·KOSIS 호출을 했다는 의미는 아닙니다.
- 배포 파일은 허용 목록으로 모았고, 키 문자열 패턴·개인 절대경로·서명된 첨부 URL·실행 로그·가상환경이 포함되지 않도록 검사했습니다. FILE_MANIFEST.json에는 배포 파일별 SHA-256이 있습니다.

## 이번에 새로 실행하지 않은 내용

새 HCX 분석 요청과 새 KOSIS 자료 조회는 실행하지 않았습니다. 공유본에는 키가 없으며 이 검수는 실제 외부 API 통과 결과가 아닙니다. 설치 후 키를 입력해 실제 질문을 실행해야 계정별 권한·호출 한도·당일 API 응답까지 확인할 수 있습니다. API 한도나 지원 범위 밖 질문에 대해서는 화면이 안내와 함께 멈출 수 있습니다.

## 유지한 범위

기존 서비스 화면과 질문 실행 코드는 유지하고, 공유본의 의존 경로만 ZIP 내부 상대경로로 바꿨습니다. 원래 작업 폴더, 키 보관함, 실행 중인 원래 서버는 수정하지 않았습니다. 개인 실행·검수 이력 화면의 기록은 배포 대상이 아닙니다.
