# A HTTP 계약

현재 경계는 `modules/a/claview_a_api/api.py`, 모델은 `common/claview_common/contracts/a_http.py`다. 계약 버전은 `a-http/2026-11-02.1`이며 요청에서 명시한다.

| 경로 | 입력·출력 |
|---|---|
| `POST /a/select` | `contract_version`, `query`, 선택 `as_of` → AView·실행 모드·meta |
| `POST /a/answer` | 계약 버전, `session_id`, `answers` → 답 적용 후 AView |
| `GET /a/records/{session_id}` | 보관한 세션 결과 복원, 신규 판단 없음 |

선택 답에는 `question_id`, `question_version`, `option_id` 또는 `text`가 필요하다. 서버의 보관 상태와 대조해 위조·다른 세션·오래된 답을 거절한다. 답 적용은 모델을 호출하지 않는다. 브라우저에서 전체 checkpoint·모드·기록 경로를 지정하지 않는다.

`as_of`는 유효한 ISO 날짜다. 생략하면 서버 실행 기준일을 사용한다. 데이터가 해당 날짜의 과거 판본이라는 뜻은 아니다. A HTTP는 A만 실행하며 B·조회·C 결과를 뜻하지 않는다. 전체 흐름은 frontend → pipeline 경로로 확인한다.

예시 요청은 `common/fixtures/a_http_request`, 응답은 `common/fixtures/a_http_result`에 있다. 재생성은 `python pipeline/scripts/build_fixtures.py --a-http-only`다. 전체 계약과 답 검사는 `modules/a/tests_api/test_a_http_1102.py`, `common/tests/test_a_http_contract.py`에서 확인한다.
