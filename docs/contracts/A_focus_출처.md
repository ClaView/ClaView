# 새 A의 표별 대상 설명과 출처

새 A 출력 계약은 .7부터 원문 인용 `statistics.quote`와 B가 참고할 표별 대상 설명을 구분한다. 이 구조는 .9에서도 유지하며, 실행한 계약·지시문 판은 실행 기록에 남긴다. 화면 계약은 `a-view/2026-11-02.12`이다. B의 입력 필드는 바꾸지 않는다.

```json
{"focuses": [{"for": ["s1"], "text": "표가 맡은 기관·지표·하위 대상", "quotes": ["원질문의 연속 구절"]}]}
```

- 통계마다 한 행을 낸다. `for`는 그 통계 하나만 가리키며 누락·중복·알 수 없는 참조를 거절한다.
- 모델은 원질문의 의미를 읽어 100자 이내 대상 설명을 쓴다. 공유 대상과 하위 항목은 보존하고, 다른 통계의 대상이나 질문에 없는 항목·코드는 더하지 않는다. 표 선택 근거는 B 계열 정답 목록이 아니다.
- 코드는 각 인용의 원문 존재와 길이·참조를 검사한다. 통계 인용과 focus 인용은 같은 공백 무시 검사를 쓰며, 원래 인용 문구는 보존한다. 낱말이나 문장부호가 달라진 인용까지 허용하지 않는다. `grounded`는 출처 확인일 뿐 의미가 정확하다는 인증이 아니다. 의미 누락·잘못된 요약은 별도 평가 대상이다.
- 잘못된 인용과 길이 초과는 해당 통계를 막고, 기존 한 번의 복구 예산 안에서 교정한다. 추가 재시도나 1→여러 통계 복구는 만들지 않는다.
- 서로 다른 기관·기준의 결과를 각각 요청하면 첫 판단에서 통계를 분리한다. 한 결과에 여러 조건을 동시에 요구한 경우나 같은 표의 하위 항목 비교를 무조건 분리하지 않는다.

`check`가 검사한 설명은 `AView.statistics[].focus`로, 인용·출처·검사 상태는 `focus_provenance`로 간다. B에는 기존 `tables[].focus` 문자열만 보낸다. 원질문, 기간·주기 조건과 A 표 선택 근거는 기존 경로를 유지한다.

같은 표·같은 조건으로 보낼 설명은 중복을 제거하고 ` / `로 합친 길이도 100자 이하여야 한다. 개별 설명이 유효해도 합친 길이가 넘으면 A 검사에서 해당 통계들을 기존 복구 한 번의 대상으로 삼고, 복구 입력에 구성 통계와 공동 한도를 알린다. 코드는 설명을 자르거나 대상을 버리지 않는다. 같은 표라도 기간·주기·답이 다르거나 아직 답을 기다리면 이 길이 복구로 조건 충돌을 대신 처리하지 않는다.

복구 결과를 고정 통계와 합친 뒤에도 길이를 검사한다. 이때 고정 통계는 바꾸지 않고 복구 대상만 실패로 남긴다. 답 적용 뒤 표가 같아지는 경우에도 화면의 최종 길이 검사는 유지되며 추가 모델 호출은 만들지 않는다.

계약 .6 이하의 저장 응답은 원래 `statistics.quote`를 focus로 유지하고 `legacy_quote / verified_quote_only`로 표시한다. 새 설명을 보충하거나 새 지시문의 응답으로 간주하지 않는다. .7 합성 시험과 옛 저장 응답 재생은 모두 코드 경로 확인이며 새 모델의 해석 품질 근거가 아니다.

사용자 기준 답으로 표가 바뀌어도 대상 설명은 바뀌지 않으므로, 모델은 아직 선택하지 않은 기준을 설명에 단정해서 넣지 않는다. 계열별 표시 요구와 B·C2의 조건 재해석 문제는 이 변경 범위 밖이다.
