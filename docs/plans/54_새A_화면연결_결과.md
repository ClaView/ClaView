| 경고 표시(54b) | A 경고의 코드·축·요청 값·표·단계를 AView에 보존, 화면 응답 `a_warnings`와 결과 카드에 표시. 경고만으로 상태를 바꾸지 않음 |

### 합성·저장 응답으로만 확인한 것

- 판단기: 각본·가짜 판단기, 저장 응답 재생(71건). 모델 성능 근거가 아니다.
- B·조회: 합성 B 모델과 합성 조회. 기간·주기는 B 코드가 정하므로 대조 결과는 의미가 있으나 항목 선택·값은 확인하지 않았다.
- 기간 직접 입력: 시험용 질문 공급자로만 입력·보존·재개 확인. 실제 B 계약으로는 보내지 않는다(`period_answer_contract_pending`).

### 정책·B 합의가 필요한 것

1. B 기간 계약: 표·통계별 기간·주기 칸이 없어, 판본 구간·통계별 기간·떨어진 기간은 지금 전달하지 못하고 미지원으로 남는다.
2. 실제 A의 기간 질문 생성과 기간 정책 전반.
3. focus 최종 형식(지금은 계획 32 제안 형식).
4. 실호출 경로: 평가기의 호출 한도 검사(CallGate)와 연결한 뒤에 켠다.
5. `selected_unverified`는 B로 넘기지 않는 현재 정책 유지.
6. 계산용 기준 시점: B가 계산 종류와 필요한 기준 시점 범위를 결과에 밝히고 그 범위만 더 조회할 때만 허용하기로 했다. 지금 B 결과에는 그 표시가 없어(B는 질문 문구로 앞 시점을 늘리고 결과에는 기간만 남김) CV-AB-18처럼 앞 시점이 늘어난 요청은 조회하지 않는다. B 계약 항목이다.
