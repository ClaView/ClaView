2. 새 A `ScreenPipeline`을 유일한 제품 실행기로 두고, 단계 실행·B 조회·C 표현 책임을 분리한다. 옛 A HTTP, CLI 내부 경로, 공통 옛 응답 모델과 전용 코드·시험·자료를 제거한다.
