- 출처: [CLOVA Studio 상품 페이지의 요금 탭](https://www.ncloud.com/product/aiService/clovaStudio), [이용량 제어 정책](https://guide.ncloud-docs.com/docs/clovastudio-ratelimiting)

## 1. 공개 요금

한국 리전 / KRW / 실시간 인퍼런스 / 기본 모델·익스플로러 / VAT 별도. 튜닝·스킬셋·학습 요금은 제외합니다. 표의 단위는 1,000토큰당 원입니다.

| 리소스 | 입력 단가 | 출력 단가 | 적용 방식 |
| --- | --- | --- | --- |
| HCX-DASH-001 | 1 | 1 | 입력+출력에 같은 단가 |
| HCX-DASH-002 | 0.25 | 1 | 입력/출력 별도 |
| HCX-003 | 5 | 5 | 입력+출력에 같은 단가 |
| HCX-005 | 1.25 | 5 | 입력/출력 별도 |
| HCX-007 | 1.25 | 5 | 입력/출력 별도 |
| Re-ranking Model | 1.25 | 5 | 입력/출력 별도 |
| RAG Reasoning Model | 2.5 | 10 | 입력/출력 별도 |
| Embedding Model v1 | 0.1 | 해당 없음 | 시험의 inputTokens로 산정 |
| Embedding Model v2 | 0.2 | 해당 없음 | 시험의 inputTokens로 산정 |

이 표는 기준일의 조사값을 보존한 것이며 현재 단가를 보장하지 않습니다. 실제 이용·예산 확정 전에 공식 요금 탭에서 재확인하고, 변경 시 기준일을 갱신합니다.

## 2. 저장된 13회 요청의 공개 단가 환산

```text
대화·응답 도구 = 입력 토큰 × 입력 단가 / 1000 + 출력 토큰 × 출력 단가 / 1000
임베딩 = 반환된 inputTokens 합계 × 임베딩 단가 / 1000
```

| 리소스 | 요청 수 | 입력/출력 토큰 | 환산액(원, VAT 별도) |
| --- | --- | --- | --- |
| DASH-001 | 1 | 192 / 76 | 0.26800 |
| DASH-002 | 1 | 226 / 30 | 0.08650 |
| HCX-003 | 1 | 192 / 28 | 1.10000 |
| HCX-005 | 1 | 226 / 76 | 0.66250 |
| HCX-007 | 1 | 226 / 34 | 0.45250 |
| 임베딩 v1 | 3 | 110 / — | 0.01100 |
| 임베딩 v2 | 3 | 117 / — | 0.02340 |
| 리랭커 | 1 | 133 / 124 | 0.78625 |
| RAG Reasoning | 1 | 73 / 76 | 0.94250 |
| 합계 | 13 | 입력 1,495 / 출력 444 | 4.33265 |

약 4.33원은 2026-09-22 초기 시험의 저장된 요청만을 공개 단가로 비례 환산한 참고값이며 결제 내역이 아닙니다. 최소 과금·반올림·계약 할인·무료 크레딧·계정의 다른 호출·정산 방식은 반영하지 않았습니다. RAG는 첫 요청 비용만이며 최종 답변까지의 비용이 아닙니다. 토큰 상한과 실제 생성 토큰은 다릅니다.

HCX-007과 005는 공개 단가가 같아도 출력 길이·추론 설정·호출 단계에 따라 총비용이 달라집니다. 이번 007 환산액이 더 작다는 이유로 항상 더 저렴하다고 결론 내리지 않습니다.

## 3. 실제 프로젝트 예산 계산

- 대화: 질의 수 × 질의당 단계별 호출 수 × 단계별 입력·출력 사용량.
- 임베딩: 최초 색인 + 변경 문서 재색인 + 질의 임베딩. 문서 벡터는 캐시해 재사용.
- RAG/리랭커: 도구 선택·검색 결과 재전달·최종 생성·재시도를 모두 포함.
- 모델 비교: 사례 수 × 모델 수 × 반복 수 × 사례당 호출 수.
- 별도 비용: 서버·저장·벡터 DB 등은 이 표에 포함하지 않음.

전수 메타의 실제 토큰량·질의량이 없어 주간/월간 예산은 아직 산출하지 않습니다. 작은 메타 2개의 호출 비용을 전체 서비스 비용으로 확대하지 않습니다.

## 4. 공개 테스트 이용량 기준

공식 가이드는 이 표의 기준일을 2025-07-17로 표기합니다. 2026-09-22 열람 기준이며 제공 키의 실제 설정·서비스 앱 한도와 같다고 확정하지 않습니다.

| 모델·도구 | QPM | TPM |
| --- | --- | --- |
| HCX-DASH-001 | 200 | 30,000 |
| HCX-DASH-002 | 90 | 80,000 |
| HCX-003 | 200 | 30,000 |
| HCX-005 | 60 | 60,000 |
| HCX-007 | 60 | 60,000 |
| 임베딩 v1 | 60 | 별도 값 미표기 |
| 임베딩 v2 | 60 | 40,000 |
| 리랭커 | 60 | 45,000 |
| RAG Reasoning | 60 | 30,000 |

- 한도는 메인 계정·모델/도구·이용 목적 기준입니다. 서브 계정도 메인 계정에 합산됩니다. 키를 여러 개 받았다고 한도가 늘어난다고 가정하지 않습니다.
- 일반 생성 요청의 TPM 산정은 입력 토큰과 예약한 최대 출력 토큰의 합입니다. 임베딩 v2는 입력만 계산합니다. 실제 출력 usage로 계산하는 비용과 다릅니다.
- 한도 이내라도 지연·실패가 발생할 수 있습니다. 이번 시험은 최대 처리량 시험이 아닙니다.
- 실제 한도는 허용된 응답 헤더인 x-ratelimit-limit-requests/tokens, remaining, reset 값으로 확인할 수 있습니다. 현재 결과 JSON에는 이 헤더를 저장하지 않아 실제 키 한도는 미확인입니다.
