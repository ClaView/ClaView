# KOSIS 조회 조건과 검증 절차

- 담당: 데이터 담당 / 팀 검수, 정리: 채진현
- 정리일: 2026-09-22
- 상태: 2026-09-16 조회 기록 기반, 최신 메타·전체 값 재검수 필요
- 근거: [KOSIS 개발 가이드](https://kosis.kr/openapi/devGuide/), 기존 팀 조회 기록

## API를 사용하는 순서

| 단계 | 확인할 것 |
| --- | --- |
| 목록·검색 | 한국은행 기관 범위와 후보 표 ID·명칭 |
| 표 메타 확인 | ITEM, 분류별 선택값, 주기·기간·단위·주석 |
| 조회 계획 | 실제 코드·기간·주기를 확정하고 조건 유효성 검사 |
| 자료 조회 | API 응답과 키를 제거한 요청 조건 보존 |
| 원표 대조 | 같은 표·항목·분류·기간·주기로 값과 주석 확인 |
| 비교·가공 | 단위·기준·기간 차이와 변환 규칙 기록 |

검색 결과에 표가 나타나는 것만으로 요청한 지표를 포함한다고 판단하지 않습니다. 표 전체의 수록기간도 개별 계열의 완전한 수록을 보장하지 않습니다.

## ITEM과 분류값을 구분하는 예시

기록 기준일: 2026-09-16. 새 호출 전 현재 메타로 코드·기간을 확인합니다.

| 조건 | 신규취급액 기준 | 잔액 기준 |
| --- | --- | --- |
| orgId | 301 | 301 |
| tblId | DT_121Y006 | DT_121Y015 |
| itmId | 13103134553999 | 13103134612999 |
| objL1 | 13102134553ACC_ITEM.BECBLA03 | 13102134612ACC_ITEM.BECBLB0202 |
| 분류 의미 | 가계대출 | 가계대출 |
| 기록된 조회 기간 | 202308~202607 | 202308~202607 |
| 주기 | M | M |

‘가계대출’은 분류값이며 공통 ITEM 코드와 구분합니다. 두 기준은 개별 계열로 비교합니다. 조회 기록은 각각 36개 월 자료이며, 골든셋 등록 전 공용 원자료·원표와 대조합니다.

## 재현 결과에 남길 항목

- 키를 제거한 실제 요청 조건과 실행 코드 버전
- 원 응답과 사람이 확인할 표 형태의 자료
- 기간별 행 수·중복·누락·단위·항목·분류 검사 결과
- 원표 대조 조건·확인일·대조한 시점과 값·불일치 내역
- 잠정치·개편·소급 수정 등 선택 계열에 해당하는 주석
- 조회 실패 시 응답 종류·재시도·미확인 원인

‘최근 N개 시점’이 반드시 결측 없는 연속 N개월이라는 뜻은 아닙니다. 비교 재현에는 고정 기간을 우선 기록하고, 최신 자료를 조회할 때는 실제 반환된 종료 시점도 남깁니다.

DT 원문과 숫자 해석 결과를 구분해 결측 기호·정밀도를 보존합니다. 갱신된 수치와 과거 저장값이 다르면 곧바로 오류로 단정하지 말고 조회 시점과 개정 여부부터 확인합니다.

## 실행 코드 인계

KOSIS 수집·조회 스크립트의 저장소 통합과 팀원 재현은 진행 전입니다.

코드 인계 시 상대경로, 의존성, 환경변수, 키 마스킹, 실패 기록, 소규모 샘플과 테스트를 확인하고 이 문서에 실행 방법을 추가합니다. 원 응답·대형 자료는 기본적으로 Git에서 제외하며 팀 공용 보관 위치 또는 재생성 절차를 제공합니다.
