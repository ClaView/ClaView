- 전체 수행 범위, 기능별 책임, 데이터 검수·조회·평가 초안.
- 9종 공식 사양·API 사용법, 13회 최소 호출 결과와 제한적인 내용 평가.
- 공개 요금·이용량 기준과 제공 키에 대해 남은 확인 질문.

최종 모델 선정이나 대규모 성능평가까지 기다릴 필요는 없습니다. 연결 확인·내용 검수·미측정 항목을 구분해 공유합니다.

## 4. 제외 대상

- `.env`, 실제 키, 인증 헤더, 비공개 입력.
- `artifacts/`의 원본 응답·실험 로그.
- `.venv/`, 캐시, 개인 조사 문서, 로컬 절대경로.
- 검수하지 않은 자료나 생성 결과 전체.

`git add .`나 폴더 전체 추가 대신 위 파일을 지정합니다. 환경 PR의 상태를 확인한 뒤 프로젝트 문서와 NCP 조사·실험을 별도 커밋 또는 PR로 나누면 검토하기 쉽습니다. 기존 환경 파일은 변경되지 않았다면 다시 추가하지 않습니다.
