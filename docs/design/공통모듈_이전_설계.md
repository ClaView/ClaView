# 공통 모듈 현황과 후속 범위

2026-11-05 정리 기준. [현재 구조](../ARCHITECTURE.md)가 실행 기준이다.

- A·B·C 본체의 상호 import 금지를 유지한다. A 본체의 상대 import·의존 제한도 유지한다.
- 계약은 공통 Pydantic 모델로 관리한다. A HTTP/AView와 B 요청·기간 해석 결과를 구분한다.
- C의 기간 계산·라벨은 `claview_common.periods`를 사용한다. 함수 사본을 다시 정의하지 않는다.
- A 카탈로그와 B 메타는 소비 형태와 검증 정책이 다르다. 파일을 같이 읽는다는 이유만으로 하나의 가변 객체로 합치지 않는다.
- A·B의 모델 클라이언트도 요청 계약·원장·복구 정책이 다르다. 공통화할 때는 네트워크 전송과 각 모듈의 정책을 구분하고 호출·오류 의미 보존 시험을 먼저 작성한다.
- C 특정 지표 규칙의 데이터화, B의 연구용 HCX 도구 정리, 카탈로그 로더 통합은 이 배포 정리에서 일괄 변경하지 않았다. 각 소비 계약과 회귀 근거가 필요하다.

현재 배포 정리는 서비스 경로·평가 도구 분리와 중복 실행기 제거를 먼저 완료하는 범위다. 신규 공통화가 외부 호출 수나 통계 의미를 바꾸면 별도 변경으로 검증한다.
