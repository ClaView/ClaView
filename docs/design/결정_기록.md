# 결정 기록

레포를 팀에 넘기는 시점(2026-10-26)에 정한 기본 결정과 후속 구현 상태다. "담당"은 다시 판단할 권한이 있는 사람이다. 바꾸면 이 표를 고치고 PR 설명에 이유를 적는다.

상태: **확정**(그대로 진행) · **기본값**(현행 유지, 담당이 바꿀 수 있음) · **과제**(담당이 처리할 일로 배정)
