# 제안서 개발계획 요약

- 담당: 채진현
- 갱신일: 2026-09-22
- 기준 자료: 제출 제안서 v0.7, 통합 구조도 v0.1(2026-09-17), 이후 팀 합의
- 상태: 수행 방향 정리, 기능별 계약·세부 기술은 검토 중

## 해결할 문제

통계 비교에는 일상 표현에 맞는 표 탐색, 항목·분류·기준 선택, 시계열 정렬, 값·출처 확인이 필요합니다. ClaView는 이 과정을 자연어 질문으로 연결합니다.

대상은 KOSIS Open API 내 한국은행 소관 통계표 전체입니다. 금리 사례는 구현·검증의 시작점으로 사용합니다.

## 구현 방향

| 단계 | 처리 내용 |
| --- | --- |
| 준비 | 전체 목록·메타 수집, 용어 매핑, 검색 문서·색인 구성 |
| 탐색 | 질문 조건 추출, 공식 메타 후보 검색, 의미 차이 확인 |
| 조회 | 표·항목·분류·기간·주기 검증, API 호출·응답 검사 |
| 가공 | 필요한 시점 정렬·변환·병합과 처리 기록 |
| 출력 | 표·그래프, 조회 조건·출처·가공 기록·주의사항 |
| 연동 | 공통 통계 기능을 MCP 도구로 제공 |
| 평가 | 도구별 시험, 단계별 평가, E2E 성공 여부와 개선 비교 |

## 대표 사례

- 질문: 2023년 8월부터 2026년 7월까지 가계대출 금리를 비교해줘.
- 확인 조건: 예금은행, 신규취급액·잔액 기준 비교, 월별 주기.
- 대상: DT_121Y006, DT_121Y015의 가계대출 계열.
- 조회 기록: 두 계열 각각 36개월, 총 72개 관측값.
- 검수 상태: 전체 값의 원표 대조 및 평가셋 등록 전 재검수 필요.
- 결과: 월별 비교 표·그래프, 선택 조건, 표 ID, 정렬 방식, 잠정치·집계 기준 안내.

제안서의 결과 화면은 저장된 API 응답을 사용한 목업입니다. 에이전트 동작 검증은 구현 후 수행합니다.

## 주차별 개발 목표

| 주차 | 목표 | 확인할 결과 |
| --- | --- | --- |
| 1주 | 통계표 관찰·개발 기반 | 목록·메타 현황, 구조 사례, 환경, 규격·골든셋 초안 |
| 2주 | 자연어 통계표 탐색 | 검색 후보·근거·기준선·용어 매핑 |
| 3주 | 조회·병합·MCP 초기 구현 | 조회 재현, 정합 규칙, 도구별 시험 |
| 4주 | 시각화·대화·전체 연결 | 정상·조건 확인·실패 경로, 외부 클라이언트 연동 |
| 5주 | 종합 평가·오류 분석 | 단계별·도구·E2E 결과와 개선 우선순위 |
| 6주 | 성능 개선·최종 검증 | 개선 전후 비교, 회귀 시험, 제한사항 |
| 7주 | 문서화·발표 준비 | 실행 안내, 최종 산출물, 시연·리허설 |

수행 기간은 2026-09-21~11-10입니다. 공휴일과 최종 발표 일정을 반영한 업무 기한은 노션 전체일정에서 관리합니다. 데이터·사전·골든셋 보완과 기능 시험은 전 기간 병행합니다.

## 협업과 산출물

매주 직전 또는 첫날에 업무·담당·완료 기준을 정합니다. 입출력 변경은 관련 담당자와 공유하고 부분 연동을 확인합니다.

최종 산출물은 E2E 에이전트, MCP 서버·외부 연동, 골든셋, 평가 방법·측정·개선 결과, 실행 문서와 발표 자료입니다.
