## 목표와 범위

자연어 질문을 KOSIS Open API 내 한국은행 소관 통계표와 세부 계열에 연결하고, 실제 자료를 조회하여 필요한 정합·병합 후 표·그래프와 근거를 제공하는 에이전트 PoC를 만듭니다.

| 구분 | 내용 |
| --- | --- |
| 대상 | KOSIS Open API 내 한국은행 소관 통계표 전체 |
| 선택 조건 | 표뿐 아니라 항목·분류·통계 기준·기간·주기까지 질문과 맞춤 |
| 처리 흐름 | 자연어 탐색 → 조회 → 필요한 정합·병합 → 표·그래프·근거 설명 |
| 필수 결과물 | E2E 에이전트, MCP 서버와 외부 클라이언트 연동, 골든셋, 정성·정량 평가 및 개선 결과 |
| 제외 | 한국은행 외 기관 통계, ECOS 등 KOSIS 외 수치 소스 연동, 상용 인증·과금·운영 |

대표 사례는 구현·검증 순서에 사용합니다. 전체 목록은 버전별로 관리하고, API 미제공·조회 실패 자료는 예외 목록에 남깁니다. 수치 소스 변경과 범위 변경은 별도 합의합니다.

## 공통 처리 원칙

1. 원자료 수치는 실제 API 응답에서 얻고 파생값은 코드로 계산합니다.
2. 신규취급액/잔액처럼 의미가 달라지는 조건은 사용자의 의도를 확인합니다.
3. 기본값을 쓰면 적용한 조건과 변경 방법을 알립니다. 기본 기간·확인 횟수는 미확정입니다.
4. 데이터·조회 조건·출처·가공 기록·주의사항을 구분해 전달합니다.
5. 검색 미적중, 범위 밖, 수록기간 밖, API 오류를 구분합니다.
6. 명칭·기준 변경을 단순 동의어로 합치지 않고 적용 시점과 메타 버전을 기록합니다.

## 미확정 사항

LangGraph, 벡터 DB, 하이브리드 검색, 후보 재정렬, 모델 조합과 UI는 검토 중입니다. 심층 경제 보고서·외부 문서 RAG는 핵심 범위 밖의 확장 후보입니다.

기능 책임은 [처리 구조](../architecture/처리흐름과_기능별_책임.md), 결정이 필요한 항목은 [설계 검토 목록](../decisions/설계결정과_검토사항.md)을 기준으로 논의합니다. 일정·기한·담당별 업무 상태는 팀 노션을 기준으로 관리합니다.
