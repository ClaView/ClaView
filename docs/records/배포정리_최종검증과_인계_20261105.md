## 옛 A 의존성 최종 확인

검사는 삭제된 Git 경로를 제외하고 **미추적 신규 파일도 포함**했다.

- 제품·현행 스크립트 Python **166개**의 AST import와 리터럴 동적 import를 확인했다. 옛 A 패키지, 이전 `claview` 패키지, 삭제한 pipeline 실행 모듈을 향하는 import는 **0건**이다.
- 코드·설정·CI·Docker·현행 실행 문서에서 삭제 패키지·라우트·평가 자료를 부르는 참조는 **0건**이다. 현행 문서는 루트 안내, 구조, 계약, 가이드, 결정 기록을 기준으로 구분했다.
- 옛 A 패키지·전용 시험, 옛 API service, 이전 pipeline 실행 모듈, 삭제 대상 A 평가 자료 경로가 실제로 없다.
- 이미지에는 옛 패키지뿐 아니라 시험·연구·문서 폴더도 없다. A 라우트는 `/a/select`, `/a/answer`, `/a/records/{session_id}` 세 개뿐이다.

**저장소 전체에서 과거 이름이 문자 그대로 0개인 것은 아니다.** 다음은 실행 의존성과 구분해 유지했다.

1. `modules/a/tests_api/test_service_boundary.py`의 옛 패키지 부재 단언과 A 경계 시험의 금지 import 예시. 삭제한 구현을 실행하는 시험이 아니라 재유입을 막는 시험이다.
2. 날짜가 붙은 과거 계획·측정·검증 기록과 출처 자료. 당시 사실을 현재 동작처럼 바꾸지 않는다.
3. `research/c/legacy_web/`의 이전 연구 화면과 옛 `claview` import. 현행 제품·CI 실행 경로와 Docker 이미지에 포함하지 않으며, 현재 제품으로 실행 가능한 도구라고 안내하지 않는다.

## 나중에 고칠 숫자 표시 문제

현재는 기준 main의 숫자 표시 정책을 유지한다. 아래는 후속 문제 목록이며 이번 인계에서 구현할 요청이 아니다.

| 구분 | 현재 동작·후속 검토 사항 |
|---|---|
| 원수치 정밀도 | 기본 소수 1자리 표시에서 `5.04 → 5`, `4.85 → 4.9`가 되어 금리 차이가 흐려진다. 원자료·CSV의 수치는 유지돼 있다. |

| 철회한 변경의 회귀 | 원수치의 모든 소수를 보존하려던 포맷터가 B 월→분기 평균 `4.793333`도 원수치로 취급했다. 원복 후에는 기존 `4.8`로 표시된다. |
| 최대 소수 2자리 검토안 | 예: `4.793333 → 4.79`, `5.04 → 5.04`, `5 → 5`. 사용자와 방향만 논의했으며 적용하지 않았다. 아주 작은 값·큰 금액·단위별 적절성은 별도로 정해야 한다. |

회귀의 원인은 `derived`의 의미를 잘못 확대 적용한 데 있다.

- [B 주기 정렬](../../modules/b/claview_b/align.py)은 평균·합계·기말 선택을 `alignment.frequency_conversions`에 기록하고 변환 전 값은 `source_points`에 보존한다. `derived`를 붙이는 계약이 아니다.
- [C 계산 카드](../../modules/c/claview_c/c_analysis.py)의 `derived=True`는 C에서 만든 전년·전월 대비 증감률 카드를 구분한다. 모든 가공값을 나타내는 공통 표시는 아니다.
- 철회한 포맷터는 `derived`가 없으면 원수치라고 간주했다. B가 만든 평균도 계산값이므로 이 가정이 틀렸다. 단순히 B 평균에 `derived=True`를 붙이면 [화면 빌드](../../frontend/build/ui_build.py)의 `%` 안내·증감률용 표시에도 영향을 줄 수 있다.

후속 작업에서는 C 담당·멘토와 원수치·주기 변환값·증감률의 표시 정책을 정하고, 표시 자릿수를 계산 이력과 구분해 다룬다. 계산값 자체를 화면 반올림 값으로 덮어쓰지 않는다. 실제 자릿수가 있는 비정수 사례, 월→분기 평균, 작은 소수·음수·큰 금액, 단위별 축 눈금, 수치표·툴팁·접근성 설명·CSV를 함께 확인한다. 골든 합성 재생의 값이 모두 `1`인 사례만으로 숫자 표시를 검증하지 않는다.

## 재현 방법

저장소 루트에서 Python 3.12 개발 환경과 [README](../../README.md)의 PYTHONPATH를 사용한다.

```powershell
python -B pipeline/scripts/check.py
python -m ruff check .
lint-imports
$tests = Get-ChildItem frontend/tests -Filter *.cjs | ForEach-Object FullName
node --test $tests
python -B frontend/build/ui_build.py
Get-ChildItem frontend/dist -Filter script-*.js | ForEach-Object { node --check $_.FullName }
python -B pipeline/scripts/golden_replay.py check --mode replay
git diff --check
```

Docker의 최종 원복본 재빌드·전체 흐름·재시작 복원은 [커밋 전 최종 확인](커밋전_최종확인_20261105.md)의 절차를 따른다. 실제 제공자 호출을 재현하려면 [실호출 안내](../guides/Docker_실호출_실행.md)에 따라 호출 수·비용 범위를 별도로 정한다. 위 합성 시험 명령으로 실호출 검증을 대신하지 않는다.

생성 로그·원응답·화면 산출물과 개인 실행환경 정보는 공유 Git 기록에 포함하지 않는다. 시험 결과와 실행 시점, 원복 범위, 재현 방법을 기준으로 검토한다.
