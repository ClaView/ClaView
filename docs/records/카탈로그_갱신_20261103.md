# 한국은행 카탈로그·메타 갱신 (2026-11-03)

## 반영 범위

KOSIS 기관별 목록의 한국은행(기관 301) 아래에서 383표를 확인했다. 기존 등록 349표는 모두 남아 있어 이 표들의 목록·설명 메타를 함께 갱신했다. 추가 발견 34표는 산업연관표이며 [등록 대기 자료](../../data/catalog/discovered_tables_20261103.json)로 분리했다. 이 발견만으로 최근 신규 공표된 표라고 판단하지 않는다.

A·B의 기본 실행 경로는 같은 `search_catalog.json`·`boK_meta_raw.jsonl`을 읽는다. 정책·계약·검색 사전·축 역할·판본 관계를 바꾸지 않았고 모델과 통계 수치를 호출하지 않았다. 자료 갱신이므로 메타 해시를 고정한 기존 실호출 승인은 새 실행에 재사용하지 않는다.

이번 후보 파일은 갱신됐지만 기존에 실행 중인 Docker 서버는 재시작하지 않았다. 운영 적용 시에는 검토한 판으로 이미지를 다시 만들고 A·B와 pipeline의 실제 파일 해시를 확인해야 한다. 실행 기록 volume과 호출 원장은 유지한다.

## 공식 출처·보존

- 공식 API: [기관별 통계목록](https://kosis.kr/openapi/devGuide/devGuide_0101List.do), [통계표설명](https://kosis.kr/openapi/devGuide/devGuide_060101List.do).
- 목록 `MT_OTITLE`, 시작 목록 `301`을 순회하고 표마다 `TBL`·`PRD`·`ITM`·`UNIT`·`CMMT`를 수집했다. ECOS를 직접 수집한 자료는 아니다.
- 중단 시도 2회를 포함한 실제 HTTP 전송 2,068회, 완료 묶음의 고유 응답 2,053개(목록 138 + 표별 메타 383×5). 자동 재시도 0회다.
- 마지막 실행은 새 전송 1,742회와 검증한 기존 응답 311개를 사용했다. 세 시도의 원응답과 요청 기록은 별도 증거 묶음에 보관했다. 키·키가 포함된 URL은 기록하지 않았다.
- 빈 목록 가지를 처음 만난 경우와 공식 JSON 문자열의 잘못된 역슬래시 escape 때문에 앞선 두 시도를 멈췄다. 최종 순회에서 빈 가지는 총 17개다. escape는 한 응답의 6곳만 파싱용 사본에서 보정했고 원 HTTP 바이트는 그대로다. 재사용한 응답의 매개변수·경로·크기·SHA를 확인했다.
- [스냅샷 manifest](../../data/catalog/metadata_snapshot.json)에 전체 383표·활성 349표·등록 대기 34표의 범위와 해시를 기록했다. 기존 원자료는 Git 이력·외부 증거 사본과 [시험용 고정 묶음](../../eval/fixtures/metadata_before_2026_11_03.zip)에 보존했다. 과거 실행 원응답·문항·기대값·원장은 수정하지 않았다.

추가 34표에는 역할 미확정 68축·4,194값이 있고, 4표(`DT_271Y013`, `014`, `073`, `074`)에는 미지원 비정기 주기 `IR`이 포함된다. 원문을 지우거나 연간으로 바꾸지 않았다. 축 역할·두 축 조합 선택·판본·비정기 주기를 검수한 뒤 별도로 등록한다. 현재의 `unknown` 역할만으로 검색이 자동 차단되지는 않으므로, 383표를 그대로 활성화하지 않았다.

검증기는 기존 오류가 남아 있으면 종료코드 1을 반환한다. 새 오류가 없다는 설명을 전체 자료 무결점으로 읽으면 안 된다.

## 저장 응답 비교

같은 코드·질문·기준일(2026-10-29)에서 구·신 메타를 비교했다. 모델 요청이 바뀌므로 **조건부 저장 응답 재검사**이며 새 모델 정확도 측정이 아니다. 카드 참조가 다른 표를 가리키거나 조회 요청에 맞는 원응답이 없으면 공백으로 처리했다.

| 묶음 | 결과 | 의미 |
|---|---|---|
| A 62문항 | 저장 응답 63개 재적용, 사용된 카드 참조의 표 ID 이동·공백 0. ready 59, needs_answer 3 유지 | 표·focus·주기·되묻기·상태 변화 0. 모델 요청 해시는 0/63 일치 |
| 연결 12문항 | 9개 재생, 3개 수치 응답 공백 | 9개 중 정상 8개·기존 되묻기 대기 1개. 공백을 서비스 오류나 성공으로 집계하지 않음 |

A 62문항 중 `CV-AB-13`의 최근 5년은 2021-08~2026-07에서 2021-09~2026-08로, `CV-AB-15`의 최근 2년은 2024-09~2026-08에서 2024-11~2026-10으로 이동했다. 갱신한 수록 끝을 사용하는 기존 정책의 결과다. 가용 범위와 송신 메타는 36문항에서 바뀌었다.

**선택 결과가 같다는 것이 후보 목록도 같다는 뜻은 아니다.** 첫 후보 목록을 62문항 모두 비교하니 `CV-AB-04`는 29→26표, `CV-AB-05`는 33→24표로 줄었다. 나머지 60문항의 후보 집합·순서는 같았다. 새 `2025년기준` 분류값이 질문의 조회연도 `2025`와 검색에서 맞아 다른 패밀리를 밀어낸 결과다. 새 메타의 메모리 사본에서 해당 세 값을 제외하면 두 문항의 옛 후보와 순서가 복원된다. 원자료와 검색 정책은 바꾸지 않았다. 두 문항 모두 저장 응답이 사용한 표는 남아 있었고, 남은 표끼리의 상대 순서도 유지됐다. 카드 본문은 62문항 모두 바뀌었으므로 새 메타의 모델 선택 품질은 실제 호출로 따로 확인해야 한다.

연결 공백 3개는 `CV-AB-07`, `FN-RECENT-M2`, `FN-FUTURE-M2`다. 갱신한 조회 파라미터와 같은 저장 수치 응답이 없어 붙이지 않았다. 미래 범위 사례의 요청 `2020-01~2027-12`는 유지되고 조회 가능한 끝만 2026-07에서 2026-08로 바뀐다. 공백이 없는 9개는 메타 판 표시 외 C 결과·화면 카드가 동일했다. 기존 `FN-TWO-PERIODS`의 합성 B·수치 경로는 실제 저장 응답과 따로 표시했다.

전체 383표를 넣은 탐색 비교는 사용된 카드 참조가 이동한 사례가 있어 별도 보관했다. 이를 최종 활성 349표 후보의 결과와 섞지 않는다. 새 메타 기반 실제 계열 선택·수치·화면은 이번에 실호출로 확인하지 않았다.

## 회귀 시험

옛 메타의 고정 경계·저장 응답을 검증하는 시험을 원본 SHA를 확인하는 고정 fixture로 분리했다. 최초 후보에서는 B `b_part`의 기본 fixture까지 옛 판을 읽었으나, 독립 검수 뒤 기본값을 새 메타로 복원하고 옛 수록 끝을 검증하는 시험 10개 함수만 `historical_store`를 명시하게 했다. 기대 날짜·정답·정책 단언은 바꾸지 않았다. A의 축 목록 시험 한 곳은 고정 개수 13을 실제 메타 개수로 바꿨으며, 목록 상한과 미표시 검증은 유지했다. 추가로 실제 A·B·C 코드에 합성 판단·수치를 넣어 새 수록 끝의 최근 3년 계산과 명시 미래 요청 보존을 확인했다.

|---|---:|---:|
| A 본체 | 333 | 4 |
| A 표 단위 | 1,659 | 52 |
| A API | 206 | 0 |
| B | 914 | 2 |
| 파이프라인 | 290 | 0 |
| 공통 | 1,393 | 0 |

수집·재사용 28건, 스냅샷 검증기 4건, 고정 자료 검증 16건이 위 회귀에 포함된다. Windows 샌드박스의 임시 파일 교체·asyncio loopback 소켓 대기는 시험 환경 문제로 따로 진단했다. 쓰기 가능한 임시 경로와 승인된 로컬 소켓 실행에서 완료했으며 외부 네트워크 차단 fixture는 유지했다. 중단되거나 빈 로그인 실행은 통과 수에 넣지 않았다.

## 다음 작업

1. 독립 검수의 조건부 수용 의견을 반영했다. [변경분 EDA](카탈로그_변경분_EDA_20261103.md)에서 항목·주석의 합집합 22표, 62문항 첫 후보 변화, 코드 반영과 미확인 범위를 구분한다. 중단된 검수 초안의 시험 로그는 근거에서 제외한다.
2. 대표 사례의 호출·비용 상한과 기대값을 고정하고 승인받아 실제 계열 선택·수치·화면을 확인한다. 메타의 지역 부모 관계만으로 광주·전남 개별 계열의 단절 여부를 단정하지 않는다.
3. 확인 후 갱신 PR을 진행한다. 운영 적용 시 이미지를 다시 만들고 A·B·pipeline에 같은 두 파일 SHA가 들어갔는지 확인한다. 갱신 전 선택지로 기다리는 세션은 범위가 달라지면 `period_option_range_changed`로 거절될 수 있으므로 다시 질문해야 할 수 있다. 기존 서버 기록·원장은 유지한다.
4. 사전 표제어를 갱신된 공식 표명·분류·항목에 연결하고 검색 확장 효과를 별도 비교한다. 연도형 기준값의 후보 밀어내기를 확대하지 않는지, 옛 지역명과 새 지역명의 의미 범위가 같은지 확인한다. 이번에 사전 연결이나 골든 정답 기반 후보 주입은 하지 않았다.

재현 절차와 도구는 [카탈로그 갱신 안내](../guides/카탈로그_갱신.md)를 따른다.
