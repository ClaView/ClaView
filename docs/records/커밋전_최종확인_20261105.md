## 재현 방법

1. [README](../../README.md)에 따라 Python 3.12 개발 환경과 PYTHONPATH를 설정한다.
2. 별도 Compose 프로젝트에 키가 없는 시험 환경을 준비하고 `CLAVIEW_MODE=synthetic`을 명시한다. 이미지·호스트 포트·volume은 다른 실행과 구분한다.
3. `docker compose build pipeline frontend`와 `docker compose up -d --no-build --wait`를 실행한다. 시험용 설정 파일을 사용하면 두 명령에 같은 설정을 적용한다.
4. 다섯 서비스의 `/health`를 확인하고 `python -B pipeline/scripts/smoke_stack.py --url <시험용_frontend_URL>`을 실행한다. 이 스크립트는 synthetic 모드를 확인한 뒤 전체 흐름·중복 답 거절·저장 복원을 검증한다.
5. 완료된 두 실행의 result JSON을 보존하고 pipeline을 재시작한다. 기록을 다시 불러와 전체 result JSON이 같은지 대조한다.
6. 시험 스택을 종료하고 기록 volume은 재검토가 끝날 때까지 보존한다. 커밋 대상은 `git status --short`, `git diff --check`, `.gitignore`로 확인한다.

빌드·시험의 생성 로그와 화면 산출물은 Git에 포함하지 않는다. 공유 기록에는 위 결과와 재현 절차를 남긴다.
