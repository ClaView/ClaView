# 기존 349표 갱신의 변경분 EDA

## 범위와 판단

[갱신 기록](카탈로그_갱신_20261103.md)의 활성 349표만 대상으로 했다. 공식 원메타의 항목 변경 16표와 주석 변경 14표가 8표에서 겹쳐 의미 검토 대상은 22표다. 수록 기간 변경 138표는 모두 끝 연장이며, 표명·단위 변경은 없다. 추가 발견 34표는 등록 대기 상태를 유지한다.

이번 단계는 메타 의미·코드 적용·저장 응답 검사다. 실제 모델의 새 선택이나 지역별 수치 수록 여부를 입증하지 않는다. 정책·계약·사전·기존 기대값은 바꾸지 않았다.

이 표는 중복 없는 22표 분류다. 지역 관련 16표·주택 설명 2표·기준연도 3표·공표치 1표이며, 넓게 묶은 ‘지역 18표’에는 주택 설명 두 표가 포함됐던 것이다. 공표치 개정 안내는 DT_141Y002에도 있어 비배타 집계로는 2표다.

광주 코드는 **F/F00**, 전남은 **R/R00**, 새 상위 전남광주는 **V/V00**이다. 검수 회신의 F/R 표기는 원메타와 대조해 바로잡았다. 부모 추가만으로 기존 지역 시계열을 새 상위값에 합치거나 이름을 자동 교체하지 않는다.

## 실제 A·B 소비 경로 확인

- A의 617축 역할·override 적용 결과는 구·신 판에서 같다. 추가 13값, 이름 변경 3값, 부모 변경 20값을 해당 표·새 이름 질문으로 확인했고 변경된 36행 모두 A 카드에 표시됐다.
- 숫자형 분류 selector는 `2025년기준` 전체를 보며 조회연도 `2025년`만으로 해당 분류값을 확정하지 않는다. 명시 분류를 focus에서 누락하면 기존 조건 보존 검사가 작동한다.
- 옛 이름 `광주전남`으로도 세 표가 검색되지만, 해당 축의 13개·21개 값이 카드 목록 상한을 넘고 새 이름과도 다르므로 `전남광주` 값 자체는 카드에 나타나지 않는 경우가 있다. 새 이름 질문에서는 보인다. 실제 모델의 동의어 해석 여부는 실측 대상으로 남긴다.
- A·B 정규화 기간은 검증 가능한 348표 모두 같다. 기존 DT_404Y017의 메타 누락은 그대로이며 새 결함으로 세지 않는다. B의 빈 단위 보완 6표도 유효하다.
- 새 주석은 B의 원메타·모델 주석에 전달된다. 다만 선택적 v2 검색 문서 생성기의 HTML 제거가 `<6.2.4. 소비자동향조사(지역, 월)>`까지 지웠다. 실제 HTML 태그만 제거하도록 좁혀 공식 통계 참조를 보존했다. 정책·모델 계약은 바뀌지 않는다. 변경된 문서 해시로 옛 벡터가 거절되고 변경 없는 조각은 재사용된다.

## 62문항 첫 후보 전수 비교

| 문항 | 이전 | 갱신 | 제거된 후보 |
|---|---:|---:|---|
| CV-AB-04 | 29 | 26 | DT_200Y121·153·162 |
| CV-AB-05 | 33 | 24 | DT_121Y008, DT_501Y001·049·050·051·052·053·054·055 |
| 나머지 60 | 동일 | 동일 | 없음 |

새 분류값 `2025년기준`이 조회연도 `2025`와 검색 점수에서 맞아 패밀리 후보가 밀린다. 메모리 사본에서 새 세 값을 제외하면 두 문항 모두 옛 후보·순서가 정확히 복원된다. 원자료를 제거하거나 검색 규칙을 바꾼 것은 아니다.

남은 후보끼리 상대 순서·패밀리 내부 구성은 유지됐고 저장 응답이 실제로 쓴 표·참조도 같다. CV-AB-22의 최종 표가 첫 후보 밖인 것은 구·신 양쪽에 있는 기존 재검색 사례다. 카드 본문은 62/62 바뀌었으므로 ‘저장 응답의 표 선택 동일’을 ‘새 모델 입력 동일’로 해석하지 않는다.

사전 연결 전에 조회연도와 분류연도 때문에 생기는 후보 밀어내기를 별도로 검토한다. 사전 확장으로 이를 늘리거나 정답 표를 후보에 강제 삽입하지 않는다.

## 검수 후 보완과 증명 범위

- B `b_part` 기본 메타를 갱신본으로 되돌렸다. 옛 수록 끝을 단언하는 10개 시험 함수만 과거 fixture를 명시한다. 정책·날짜 단언은 유지한다.
- CI가 `data/**`와 `eval/fixtures/**` 변경에서 관련 A·B·pipeline 시험을 빠뜨리지 않게 했다.
- v2 검색 문서의 주석 참조 보존, HTML 정리, 벡터 무효화·재사용을 회귀 시험으로 확인한다. 새 메타의 실제 계열 선택 정확도와는 별개다.
- 중단된 독립 검수 초안의 import 실패 로그는 결과로 쓰지 않는다. 최종 독립 검수의 Git archive 환경 실패 4건과 원 저장소의 통과 결과도 구분한다.

보완 후 B 전체 시험은 **921 통과·2 건너뜀**, 파이프라인은 **290 통과**했다. B 문서 참조 보존 관련 7건이 추가됐고 변경 Python 파일의 Ruff도 통과했다. 파이프라인 시험은 Windows의 로컬 소켓 제한으로 첫 실행을 중단한 뒤, 외부 연결 차단을 유지한 실행에서 완료했다. 새 메타를 사용하는 기본 B 시험과 옛 메타 날짜를 단언하는 시험이 모두 통과한 결과이며, 실제 모델·수치 호출은 아니다.

## 대표 실호출 확인 항목

1. 광주 원화예금의 최근 월별 자료: 표 전체 수록 끝과 개별 지역 계열의 값이 다른지, 전남광주 상위값이 요청에 섞이는지.
2. 옛 지역명으로 한 질문: 표 선택과 B 지역 선택이 같은 대상을 보존하는지.
3. `2025년기준` 분류와 `2024년` 조회: 두 조건을 구분하는지, 해당 조합에 실제 값이 있는지.
4. CV-AB-05: 후보 축소 후 표 선택·수록 부족 안내가 적절한지.
5. CV-AB-13: 최근 N기간이 늘어난 메타 끝을 사용하고 조회까지 보존되는지.
6. DT_121Y007: 개정 안내가 있는 구간의 실제 조회·결측·표현이 정상인지. 개정 전 값이 없으면 전후 수치의 정오를 주장하지 않는다.

위 6항목은 별도 승인을 받아 후보 `203149a`에서 실행했다. A 표·기간·주기는 6건 모두 확인했고, 5건은 조회·화면까지 정상, 분류 기준연도 사례 1건은 기존 B 기간 파서 오류로 실패했다. 정상 5건의 원응답 313값·시점이 화면 데이터와 일치한다. [실호출 결과와 B 후속](카탈로그_대표사례_실호출_20261103.md)에 처음 실패한 단계와 미확인 범위를 구분했다. 기존 원장·응답·기대값은 유지했다.

운영 이미지는 아직 옛 메타다. 배포 시 A·B·pipeline의 두 파일 해시를 대조하고, 기존 대기 세션의 선택지 범위 변경 가능성을 알린다. 저장 기록과 호출 원장은 지우지 않는다.
