# 차트 숫자 표시 원복

- 상태: **worked — 사용자 요청에 따라 추가 숫자 표시 변경을 원복했다.**
- 대상: `chore/deploy-cleanup-review-1105`의 숫자 표시 원복 변경.
- 배경: 추가한 포맷터가 `derived` 표시 없는 B 주기 정렬 평균을 원수치로 취급했다. 월→분기 평균 `4.793333`이 기존 `4.8` 대신 전체 자릿수로 표시된다는 재검토 지적에 따라 변경을 철회했다.

## 원복 범위

- `frontend/build/chart_display.py`의 포인트·축 숫자 포맷터 변경을 제거해 기준 main과 동일한 내용으로 복원했다.
- 추가한 `frontend/src/chart_numbers.js`와 해당 기능 시험 4개가 들어 있는 `frontend/tests/chart_numbers.test.cjs`를 제거했다.
- 화면 빌드를 다시 실행해 원복된 코드가 생성물에도 반영되는지 확인했다.

부분 답변 안내(`screen.py`), 옛 A 제거, C 공통 기간 함수 정리와 연구용 rubric 분리는 유지했다. 공통·모듈·pipeline의 이전 변경 경로 325개를 인계 시점 해시·존재 여부와 대조해 이번 원복에서 바뀌지 않았음을 확인했다.

숫자와 축 눈금은 기준 main의 표시 정책으로 돌아간다. 따라서 앞서 확인했던 원수치 5.04의 표시가 `5`로 반올림되는 동작과 정수 축 눈금도 그대로이며, 추가 정밀도 개선은 이번 변경에 포함하지 않는다. 원자료·CSV·B 계산 결과는 바꾸지 않았다.

## 검토·인계 갱신

PR에 별도 화면 동작 변경으로 남는 것은 부분 답변 안내다. 숫자 정밀도 변경은 철회됐으므로 구현 완료 항목에서 제외한다. 검토 시 C 담당에게 숫자 정밀도 개선이 반영됐다고 전달하지 않는다.

재현은 [README의 로컬 검증](../../README.md#로컬-검증)에 따라 frontend 시험을 실행하고, `python -B frontend/build/ui_build.py`로 화면을 빌드한 뒤 생성 JS를 `node --check`로 검사한다. 생성 포맷터에 4.793333과 5.04를 입력해 위 표의 표시 결과를 확인한다. 후속 Docker 재검증은 [커밋 전 최종 확인](커밋전_최종확인_20261105.md)을 따른다.
