## 실호출에서 발견한 화면 문제 수정

### 부분 기준 답변

원인: A의 첫 판단에서 나온 축별 예시 표를 화면이 계속 보여 줬다. `말잔`에 답한 뒤에도 남은 계절조정 선택지에는 최초 예시인 평잔 표가 붙었다. 최종 실행은 두 답을 조합해 올바른 말잔 표를 선택했지만 화면은 이전 답이 취소된 것처럼 보일 수 있었다.

수정: 같은 통계의 일부 기준에 답한 상태에서는 **이미 선택한 기준을 문장으로 유지 표시**하고 남은 기준값만 선택하게 한다. 이 단계의 예시 표는 감추고 최종 표를 모든 답변 뒤에 확인한다고 안내한다. 최초 확인 카드의 표·수록 기간·단위는 유지하며, AView·선택지 ID·답변 값·모델 판단·최종 표 선택 로직은 변경하지 않았다.

회귀 시험은 두 기준 질문 → 말잔 부분 답변 → 남은 기준 화면 → 계절조정 답변 → `DT_161Y007` 완료를 실제 AView 서비스와 합성 B·조회로 실행한다. 부분 답변에서 B·KOSIS 0, 전체 답 적용에서 A 추가 호출 0, 최초 A 판단 1회도 확인한다.

### 숫자·축 눈금

원인: 포인트 표시가 기본 소수 1자리, 축 눈금은 정수 표시로 고정됐다. 원자료·CSV는 5.04, 4.85를 유지했지만 차트 설명은 5, 4.9가 되고 서로 다른 눈금이 같은 `5`로 보였다.

당시 수정: 원수치의 소수 자릿수를 차트 설명·툴팁에 보존하고 눈금에 실제 tick 값의 소수를 표시했다. `derived`가 있는 계산값에는 기존 반올림 정책을 적용했지만, 이후 B 정렬 평균에는 이 표시가 없어 소수 자릿수가 늘어나는 회귀가 확인됐다. 사용자 요청에 따라 이 변경 전체를 철회했다. 원본 HTML 시안은 수정하지 않았다.

저장된 실제 대출금리 결과를 로컬 표시 전용 서버로 열어 접근성 설명의 `5.04`, `4.85`와 y축 `4.4 / 4.6 / 4.8 / 5 / 5.2`를 확인했다. 표시 전용 서버는 새 질문·답변 요청을 거절하고 외부 API 경로가 없으며 확인 후 종료했다.

## 배포·PR 안내의 현재 상태

백엔드 바인딩을 기존 방식으로 원복했으므로 루프백 전환에 관한 이전 안내 문안은 철회한다. PR에는 기존 포트 공개 방식을 유지한다고 적는다. 실제 팀 메시지는 보내지 않았으며 계정·팀·원격 보호 설정의 결정도 대신하지 않았다.
