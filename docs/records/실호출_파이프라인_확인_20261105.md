- 기준: PR #50 병합 후 `main 941666ee61f4f879a2a99c6dc2ef21325659a59e`에서 시작한 `chore/deploy-cleanup-review-1105`의 로컬 정리본. [구현·오프라인 검증](배포정리_20261105.md)을 마친 같은 이미지다.

- 실행: 별도 Docker 네트워크·컨테이너·기록 volume에서 실제 nginx→pipeline→새 A→B→KOSIS→C 경로를 사용했다. 합성 판단·합성 데이터·정답 표 주입은 사용하지 않았다.

|---|---|---|---|

| L3 | 2024년 월별 M2 통화량을 보여줘. | 평잔/말잔과 원계열/계절조정을 질문 → `말잔`만 먼저 답함 → 원계열/계절조정만 남음 → `계절조정` | `ok`, `DT_161Y007`, M2 말잔 계절조정, 2024년 1~12월, 십억원 |

각 사례는 A 첫 판단 1회, B 모델 1회, KOSIS 조회 1회를 사용했다. 부분 답변과 최종 답변 적용에서 **A 추가 호출은 모두 0회**였다. 확인 대기·부분 답변 상태에서는 **B·KOSIS 0회**이며 모든 필요한 답을 제출한 후에만 각 1회 실행했다. 화면에서 실제 반환된 질문·선택지를 골랐으며 서버의 질문 ID·판을 사용했다.

L1도 계절조정 기준이 없어 확인 질문이 필요했다. 따라서 이번 결과에 확인 질문 없이 곧바로 조회하는 경로의 실호출 검증은 포함되지 않는다. 세 사례 중 두 개는 같은 통계·조건으로 수렴하므로 세 개의 서로 다른 통계를 검증한 것이 아니다. 기능 스모크이며 정확도·성공률 평가 표본으로 사용하지 않는다.

## 거절·재시작·복원

- 제시하지 않은 선택지 제출: HTTP 400, `제시된 선택지 중에서 골라 주세요.`, 외부 호출 증가 0.
- 이미 답한 확인을 별도로 복원한 job에서 재제출: HTTP 400, `이미 답했거나 제시하지 않은 질문입니다.`, 외부 호출 증가 0. 동일 job의 409와 구분되는 세션 단위 거절이다.
- 이미 이어 실행한 원본 기록을 다시 불러오기: 세 사례 모두 HTTP 409. 소비된 확인 기록에서 재실행하지 않았다.
- L2 부분 답변 상태에서 pipeline 재시작: 기존 브라우저 job은 만료 안내를 보였으며 서버 기록에서 복원했다. `2024년`은 유지되고 남은 `월별` 답으로 실제 조회가 완료됐다.
- 세 완료 결과를 보존한 뒤 pipeline을 다시 재시작하고 `/api/records/load`→`/api/jobs`로 복원했다. **전체 result JSON이 이전과 동일**했고 세 결과의 해시를 기록했다. 화면에서도 L2 완료 기록을 다시 불러와 기간·주기·그래프·수치표를 확인했다.
- 복원·재시작 전후 제공자 호출 원장 파일은 바이트 단위로 동일했다. 확인 질문의 판, 소비 기록, 사용량을 초기화하지 않았다.

## 호출·비용

| 구분 | 실제 | 승인 상한 |
|---|---:|---:|
| OpenAI A 첫 판단 (`gpt-6.1-terra`) | 3 | 3 |
| OpenAI A 복구 (`gpt-6.1-sol`) | 0 | 3 |
| OpenAI B (`gpt-6.1-terra`) | 3 | 6 |
| **OpenAI 합계** | **6** | **12** |
| **KOSIS** | **3** | **12** |

OpenAI 응답 usage 합계는 입력 **38,626**(캐시 읽기 12,442, 캐시 쓰기 26,166 포함), 출력 **1,259**다. 출력에 포함된 추론 66토큰을 중복 합산하지 않았다.

2026-11-05 확인한 [Terra Standard 가격](https://developers.openai.com/api/docs/models/gpt-6.1-terra)은 100만 토큰당 입력 $1, 출력 $5, 캐시 읽기 $0.05, 캐시 쓰기는 30분 $1.25 / 12시간 $2.50이다. 기록에 캐시 보존 기간이 없어 두 쓰기 요금으로 계산하면 **$0.03964260~$0.07235010**이다. 이는 응답 사용량 기반 추정이며 계정 청구서를 확인한 금액은 아니다. 세금·환전 수수료는 제외했다. [KOSIS 약관 제10조](https://kosis.kr/openapi/introduce/introduce_02List.do)의 일반 API 정보 제공 기준으로 KOSIS 사용료는 $0이다.

시험용 전송 계층이 실제 전송 직전에 횟수와 비용을 영속 원장에 예약했다. 입력은 UTF-8 바이트 수와 여유분으로 잡고 최대 캐시 쓰기 요금·출력 제한·10% 여유분을 적용했다. 사용량이 없는 실패는 예약 비용을 유지하도록 했으며 자동 HTTP 재시도는 0이었다. 응답 후에도 캐시 할인을 적용하지 않고 보수적으로 계상한 최종 합계는 **$0.113146**, 승인 상한 $1 이내다. 한도·재시작·사용량 불명 실패 처리의 오프라인 시험 8개가 통과한 뒤 실행했다.

## 관측한 화면 표기 문제와 후속 수정

1. **부분 기준 답변 후 선택지의 예시 표명**: L3에서 `말잔` 답변 후 남은 계절조정 선택지에 `평잔` 예시 표명(`DT_161Y005`)이 그대로 보였다. 모든 답을 적용한 실제 조회는 `말잔` 표(`DT_161Y007`)로 올바르게 실행됐지만 사용자가 이전 답이 취소된 것으로 오해할 수 있다. 이미 답한 기준을 반영한 예시를 보여주거나 최종 표가 확정되기 전의 예시임을 명시할 필요가 있다.
2. **금리 차트 정밀도**: 원자료·CSV는 5.04, 4.85 등 원수치를 유지하지만 차트 접근성 설명은 소수 1자리로 반올림하고, y축 눈금은 정수로 표시되어 서로 다른 눈금이 `5`로 겹쳐 보였다. 작은 범위의 금리 그래프에는 구분 가능한 눈금 정밀도를 적용해야 한다.

위 두 건은 이 실호출 당시 관측한 표시 동작이다. 이후 [검토 반영](배포정리_검토반영_20261105.md)에서 부분 답변 안내와 숫자 표시를 고치고 저장된 실제 응답으로 화면을 확인했다. 숫자 표시는 B 주기 평균의 표시 회귀가 확인되어 사용자 요청으로 [원복](차트_숫자표시_원복_20261105.md)했으며 부분 답변 안내만 유지한다. 원자료·호출 기록을 덮어쓰거나 실호출을 반복하지 않았다. 실제 모델 복구 경로, 다중 통계, 병렬 사용자, 공용 배포 인증은 이번 세 사례로 검증하지 않았다.

## 재현·대조 방법

[Docker 실호출 안내](../guides/Docker_실호출_실행.md)에 따라 호출 수·비용 범위를 정하고, 위 세 질문의 기간·주기·기준 답변 순서를 재현한다. 질문마다 표 ID·기관·항목·분류·기간·단위와 원응답 수치 문자열을 C 결과와 대조한다. 인증키·토큰은 출력과 기록에서 제외한다.

부분 답변 후에는 남은 질문만 유지되는지 확인하고, 완료 뒤에는 pipeline 재시작 전후 result JSON과 제공자 호출 원장이 동일한지 대조한다. 잘못된 선택지·중복 답·소비된 확인 기록은 본문의 HTTP 상태 기준으로 검사한다.

새 모델 호출은 이 기록의 완료 검증에 포함되지 않는다. 저장 결과·원응답을 이용한 대조와 새 실호출을 구분하며, 새 실호출은 승인 범위와 질문 원장을 확인한 뒤 별도로 진행한다. 생성 로그·원응답·화면 산출물은 공유 Git 기록에 포함하지 않는다.
