A 전용 `tests_legacy`는 제품에서 제거한 규칙 엔진의 시험이다. 해당 알고리즘을 새 A가 동일하게 재현한다고 주장하지 않는다. 새 A의 선택·조건·복구는 `modules/a/tests`·`tests_tl`, HTTP는 `tests_api`로 계속 검증한다.

C 흐름의 불확정 1순위 강제 진행 시험은 제거했다. AView는 미확정 상태를 blocked로 남기며 `test_screen_54.py`의 부분·미지원·되묻기 시험이 현행 정책을 검증한다.
