# ClaView B단계 모델 성능 비교 결과 (HCX-007 vs gpt-6.1-sol)

- 작성일: 2026-10-20
- 대상: B단계(시리즈·기간 선택) 모델 비교
- 범위: 기존 골든 22건 + 신규 질문 9건 (신규 CV-NEW-07 제외), 케이스당 3회 반복

---

## 1. 목적

- B단계 모델을 HCX-007과 GPT(gpt-6.1-sol)로 각각 교체하여, 동일한 입력·프롬프트·판정 기준 아래에서 성능을 비교함.
- 모델 원본 답변의 정확도와, 프로그램 보정(이름 교정·확장 가드)에 대한 의존도를 함께 측정함.

## 2. 시험 구성

### 2.1 데이터셋

| 구분 | 파일 | 케이스 수 | 비고 |
|---|---|---|---|
| 기존 골든 | `eval/cases/golden_set_v1.json` | 22건 (CV-AB-01 ~ 22) | 기존 HCX 프롬프트·규칙 튜닝에 사용된 세트 |
| 신규 질문 | `eval/cases/golden_set_v2_new10.json` | 9건 (CV-NEW-01~06, 08~10) | 정답은 저장된 메타데이터 기준으로 작성함. 팀 확정 전 |

- 신규 CV-NEW-07은 이름 교정 규칙 보완 대상으로 분리하여 본 문서의 모든 집계에서 제외함.
- 입력은 골든의 A단계 결과(표 선택)를 그대로 사용하며, B단계만 실제 모델로 실행함.

### 2.2 판정 기준

- 모델이 최종 선택한 시리즈 집합이 골든 시리즈 집합과 일치하면 통과로 판정함.
- 통과 건은 프로그램 보정 여부에 따라 다음과 같이 구분함.
  - 보정 없는 통과: 모델 원본 답변이 그대로 정답이었던 경우
  - 보정 후 통과: 이름 교정(`named_value`) 또는 확장 가드(`expand_on_leaf`, `expand_promoted`, `expand_named`)가 개입하여 정답이 된 경우

### 2.3 실행 조건

| 항목 | HCX-007 | gpt-6.1-sol |
|---|---|---|
| 추론 설정 | thinking: none | reasoning_effort: low |
| temperature | 0 | 기본값(1) |
| seed | 42 | 미지정 |
| 최대 출력 토큰 | 6,144 | 6,144 |
| 출력 형식 | JSON 스키마 구조화 출력 | strict JSON 스키마 (minItems/maxItems 제외 후 전송, 로컬에서 전체 스키마 재검증) |
| 호출 간격 | 12초 (분당 호출·토큰 제한 대응) | 1초 |
| 반복 횟수 | 3회 | 3회 |

- 프롬프트, 입력 데이터, 판정 로직, 프로그램 규칙은 두 모델에 동일하게 적용함.
- gpt-6.1-sol은 API 제약으로 reasoning_effort 'none'과 temperature 0을 지원하지 않아 위와 같이 설정함. 따라서 추론 사용 여부와 샘플링 설정이 완전히 동일하지는 않음.

- gpt-6.1-sol은 3회 모두 정답을 선택함.

## 5. 안정성 및 토큰 사용량

### 5.1 반복 안정성

- gpt-6.1-sol: temperature 기본값(1)임에도 31개 케이스 전부 3회 결과가 동일함.
- HCX-007: CV-AB-13에서 run 2만 다른 경로(`expand_on_leaf`)를 탔으며, 최종 결과는 모두 통과함. 그 외 케이스는 3회 동일함.

### 5.2 gpt-6.1-sol 토큰 사용량

| 세트 | 호출 수 | 입력 토큰 | 출력 토큰 |
|---|---|---|---|
| 기존 22건 | 66 | 422,067 | 6,573 |
| 신규 10건 (CV-NEW-07 3회 포함) | 30 | 72,405 | 3,210 |

- 호출당 평균은 기존 22건 기준 입력 약 6.4천, 출력 약 100 토큰임.
- 신규 세트의 토큰 합계는 호출 단위로만 기록되어 CV-NEW-07 호출분을 분리하지 못함.
- HCX-007의 토큰 사용량은 결과 파일에 기록되지 않아 비교하지 못함.

## 6. 해석

- 최종 통과율은 gpt-6.1-sol 93/93, HCX-007 90/93으로 차이가 작으나, 모델 원본 정확도는 각각 100%와 64.5%로 차이가 큼.
- HCX-007은 현재 프롬프트·규칙 구성에서 이름 교정과 확장 가드가 있어야 gpt-6.1-sol에 근접한 통과율을 보임.
- gpt-6.1-sol은 HCX 기준으로 튜닝된 동일 프롬프트에서도 보정 없이 전 케이스를 통과하여, 일반화 측면에서 우세한 신호를 보임.
- 신규 질문에서 HCX-007의 실제 모델 오류(CV-NEW-10)가 확인되어, 기존 22건만으로는 드러나지 않던 약점이 신규 세트에서 나타남.

## 7. 한계 및 유의사항

1. 실행 설정이 완전히 동일하지 않음. gpt-6.1-sol은 추론(low)을 사용하고 temperature·seed를 지정하지 못하였으며, HCX-007은 thinking 없음·temperature 0·seed 42임. 추론 사용 여부의 영향이 결과에 포함되어 있음.
2. 기존 골든 22건은 HCX-007 프롬프트·규칙 튜닝에 사용된 세트이므로 HCX-007에 유리하게 편향될 가능성이 있음.
3. 신규 9건의 정답은 작성자(Claude)가 메타데이터 기준으로 도출한 것이며 팀 확정 전임. 특히 CV-NEW-03, 04, 10은 해석 의존도가 높음. CV-NEW-10의 HCX 실패 판정도 "예금취급기관" 해석에 근거함.
4. 표본이 작음(신규 9건 × 3회). 통계적 유의성을 주장하기 어려움.
5. 응답 시간(지연), 비용은 본 시험에서 측정하지 않음. 호출 간격이 모델별로 달라(12초/1초) 소요 시간 비교에 사용할 수 없음.
6. 일부 케이스는 이미 유일한 정답에 가까워 변별력이 낮음. 보정 개입 케이스(CV-AB-07, 08, 10, 12, 13, 17, 21 등)가 실질적 변별 지점임.
7. CV-AB-20 골든 변경분은 팀 확인이 필요한 상태로 남아 있음.

## 8. 후속 과제 제안

- 신규 정답(특히 03, 04, 10)의 팀 확인 및 확정
- 유사 이름·계층이 겹치는 항목 중심의 추가 질문 세트 작성 (CV-NEW-10 유형 보강)
- gpt-6.1-sol의 reasoning_effort 설정별(low/medium) 비교 및 HCX thinking 설정별 비교로 추론 영향 분리
- 지연시간·토큰 단가를 포함한 비용 대비 성능 비교
- 이름 교정 규칙 보완(분리된 항목) 후 해당 케이스 재검증
- 확장 가드·이름 교정을 끈 상태에서의 두 모델 비교(모델 순수 성능 측정)
