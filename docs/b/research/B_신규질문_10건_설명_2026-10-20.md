# B파트 신규 검증 질문 10건 (2026-10-20)

## 1. 목적

- 기존 골든 22건은 HCX용 프롬프트와 보정 규칙을 다듬는 데 쓰였으므로, 22건 통과만으로는 일반화 성능을 판단할 수 없음.
- 기존 22건이 쓰지 않은 통계표 10개에서 새 질문 10건을 만들어, 모델(HCX-007, GPT 등)을 같은 조건으로 비교하는 용도임.
- 비교 대상은 B파트(계열·기간 선택)이며, A파트 결과는 정답 표를 그대로 입력함.

## 2. 정답표를 만든 방식

- 계열 코드와 이름은 저장 메타(`boK_meta_raw.jsonl`)에서 직접 읽어 생성함(`scripts/b_part/make_new10_golden.py`). 코드 오타가 정답에 들어갈 수 없음.
- 기간의 끝은 각 표의 수록 종료 시점을 기준으로 함. "최근 N년"은 기존 골든(CV-AB-07, 12, 15)과 같은 규칙으로 계산함.
- 형식은 기존 스키마(`golden_set_v1.schema.json`)와 같고 검증을 통과함.
- 정답은 작성자(Claude)가 질문 문구를 읽고 정한 것이므로, 팀 확인이 필요함. 특히 CV-NEW-03, 04, 07, 10의 정답은 해석이 갈릴 수 있음.

## 4. 재생 점검 결과와 알려진 문제

정답 자체를 모델 답으로 넣어 재생(`--dry-run`)하면 9/10이 통과함. CV-NEW-07이 실패함.

- 원인: 질문에 "정기예금"이라는 이름이 그대로 쓰여 있어, 프로그램의 이름 보정 규칙이 정답인 `정기예금(1년)`(BEABAA2118)을 상위 값 `정기예금`(BEABAA211)으로 바꿈.
- 따라서 이 건은 모델이 정답을 내도 현재 보정 규칙 때문에 실패함. 모델 성능이 아니라 보정 규칙을 보는 문항임.
- 비교표에서는 CV-NEW-07을 나머지 9건과 분리해 보고하는 것이 적절함. 질문을 "정기예금(1년) 금리"로 바꾸면 모델 성능을 보는 문항이 되지만, 그 경우 사용자 말투와 멀어짐.
- 규칙 수정 여부는 팀 결정 사항임. 이번 작업에서는 규칙을 바꾸지 않음.

## 5. 실행 방법 (PowerShell, 프로젝트 루트)

```powershell
# HCX-007
python scripts/b_part/verify_expand_hcx.py --allow-external --golden eval/cases/golden_set_v2_new10.json --output eval/results/new10_hcx.json '@all'

# GPT (OPENAI_API_KEY 설정 후)
python scripts/b_part/verify_expand_hcx.py --allow-external --model openai --model-name gpt-6.1-sol --reasoning-effort low --max-output-tokens 16000 --delay 1 --golden eval/cases/golden_set_v2_new10.json --output eval/results/new10_gpt-6.1-sol.json '@all'
```

- 안정성까지 보려면 `--repeat 3`을 추가함.
- 결과 비교 시 통과 건수 외에 보정 개입 건수(`expand_lowered`, `expand_on_leaf`, `expand_promoted`, `expand_named`, `expand_repaired`, `named_value`)를 함께 봄.
