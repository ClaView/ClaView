ClaView B 노드 흐름

A가 확정한 표 → 상대 기간 확정 → 문맥 만들기 → 모델 선택 → 코드 검증(계층 확장·보정 포함) → 조회 좌표(selections). 노드를 누르면 팝업으로 하는 일, 입력·출력(State 필드), 방식, 중단 코드, 확인 방법을 볼 수 있고, 팝업 안에서 이전·다음 노드로 넘길 수 있다. 내용은 현재 저장소 코드(stages.py의 BSteps, graphs.py의 build_b_graph)를 읽고 정리한 것이다.

규칙 코드가 결정(모델 호출 없음) 모델 모델 1회 호출 중단 가능 조건에 걸리면 B가 그 자리에서 끝남 표마다 반복 A가 넘긴 표 수만큼 돈다

한눈에 보기

그래프 노드는 4개(load → context → select → validate)이고, 아래 세부 단계는 각 노드 안에서 도는 처리를 나눠 적은 것이다.

A 결과→ L load→ C context→ M select→ V validate→ B 결과 → fetch
validate 끝에서 남은 표가 있으면 context로 되돌아간다(표마다 반복). 확장 지정을 쓸 수 없으면 validate에서 select로 한 번 되돌아가 같은 표를 다시 묻는다. 중단 조건에 걸리면 그 단계의 outcome(status, issues)으로 B가 끝나고, 파이프라인은 status != ok이면 다음 단계(fetch)로 가지 않고 응답한다. 기간 안내(period_notices)는 중단이 아니라 B 결과에 붙는 안내다.
