# 공통 개발 환경

Python 3.12와 uv를 사용합니다. 의존성은 [pyproject.toml](../../../pyproject.toml)과 [uv.lock](../../../uv.lock)이 기준입니다.

```powershell
uv sync --locked
uv run --env-file .env --locked python -m pytest -q
uv run --env-file .env --locked ruff check src tests
uv run --env-file .env --locked ruff format --check src tests
```

저장소 루트에서 실행합니다. `.env`가 없다면 [.env.example](../../../.env.example)의 변수 이름을 기준으로 준비합니다. 키 없는 오프라인 시험은 `--env-file .env`를 생략해도 됩니다. 기존 파일을 덮어쓰지 않습니다.

키는 환경변수로 전달하고 숨김 입력은 지원 CLI의 `--prompt-key`로 명시합니다. 키 존재는 인증 성공을 뜻하지 않습니다. 일반 테스트는 [conftest.py](../../../tests/b/conftest.py)로 Python TCP 연결을 차단합니다.

설치가 끝난 제한 환경은 `uv --no-cache run --env-file .env --locked --offline --no-sync python -B -X utf8 ...`를 사용할 수 있습니다. 전체 메타와 [데이터 준비](../../../data/README.md)를 확인한 뒤 [실행·복구](../../records/A_사용자선택_실행과_복구_옛A.md)를 따릅니다.
