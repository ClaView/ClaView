# 통계어사전 v1.3 설명서

- 대상: ClaView 팀 (A단계 검색 확장, 검토 작업 담당자)
- 생성일: 2026-10-22
- 상태: **GPT 프롬프트 v5 판정 + 사람 검토 1,388건 반영본**. 미검토 항목은 998건이며 모두 신뢰도 `중간`임 (v1.2의 신뢰도 `낮음` 263건은 전수 검토로 해소)
- 개정 예정: 조회 방식 결정과 미검토 항목 추가 검토 후 v1.4
- 직전 버전(v1.2) 대비 변경은 5.10절, v1.1 → v1.2 변경은 5.7절, v1.0 → v1.1 변경은 5.4절 참조

## 1. 개요

### 1.1 목적
- 사용자가 쓰는 일상어(구어, 약어, 속어, 풀어쓴 표현)를 KOSIS 공식 통계용어(공식어)로 연결하는 사전임.
- 검색 단계에서 사용자 질문의 일상어를 공식어 후보로 **확장**하는 용도임. 질문을 공식어로 치환하는 용도가 아님.

### 1.2 생성 방식
1. 공식어별로 일상어 후보를 생성함 (CLOVA).
2. 후보를 임베딩(bge-m3)으로 역검색해 순위를 계산함. 순위는 "검색으로 얼마나 잘 찾아지는가"를 뜻하며, 사전 보강 효과의 척도임.
3. 후보와 공식어의 관계를 GPT(gpt-6.1-sol, 프롬프트 v5)가 판정함 (동의, 약어·속어, 상위, 하위, 관련, 무관).
4. 사람이 검토한 1,388건(1차 519건 + 2차 506건 + 3차 363건)의 라벨은 GPT 판정보다 우선 적용함.
5. 미검토 항목에는 이전 프롬프트(v3)와 현재 프롬프트(v5)의 판정이 같은 계열인지로 신뢰도를 매김 (3.6절). v1.3에서는 불일치 항목이 모두 사람 검토를 거쳐, 미검토 항목은 전부 일치 항목임.
6. 사전 포함 기준(4절)에 따라 사전과 보류 목록으로 나눔.

### 1.3 범위
- 대상: 우선순위 1+2 공식어 중 후보가 생성된 1,950개 (후보 7,812건).
- 제외: 산업분류코드(하이픈 코드 포함)와 물가 품목은 별도 트랙임. 업종명(코드 없는 것)은 포함함.
- 미처리: 우선순위 3 공식어. 후보 생성에 실패한 공식어 4건(`가계-수신금리연동`, `기업-수신금리연동`, `대기업대출-12%이상`, `중소기업대출-12%이상`)은 후보가 없음.

### 3.1 관계 값
- **동의**: 같은 개념을 다르게 부르는 말 (`소비자 물가` = 소비자물가지수).
- **약어·속어**: 약칭, 은어, 외래어, 구어 (`CPI`, `주담대`).
- **하위**: 일상어가 공식어의 일부·종류·구성 항목임 (`스파게티` → 면류). 사전에는 **근사 확장용**으로 포함함.
- 방향 기준은 **일상어 기준**임. 일상어가 공식어보다 넓으면 상위, 좁으면 하위로 봄.
- 상위, 관련, 무관은 사전에 포함하지 않고 보류 목록에 둠.

### 3.2 모호어
- `Y`는 다음 중 하나에 해당함.
  - 후보 생성 단계에서 같은 일상어가 여러 공식어와 가까웠음. 이 경우 `연결구분`이 `귀속`(1위 공식어로 귀속) 또는 `복수유지`(순위 격차가 작아 복수 유지)임.
  - 사전 안에서 같은 정규화키가 서로 다른 공식어 둘 이상에 걸려 있음.
- `Y`는 "다른 공식어일 가능성이 있다"는 **주의 표시**이며 오류 표시가 아님. 처리 방식(되묻기, 복수 후보 제시 등)은 호출 측에서 정함.

### 3.3 연결구분
- `단독`: 해당 일상어가 이 공식어에만 연결됨.
- `귀속`: 여러 공식어 중 1위로 귀속됨 (이 공식어가 우선).
- `복수유지`: 1위와 격차가 작아 여러 공식어를 함께 유지함.
- `비귀속`(다른 공식어에 귀속됨)은 사전에 넣지 않고 보류함.

### 3.4 검색보강
- 일상어로 검색했을 때 공식어가 상위에 이미 나오는지를 뜻함. 사전 효과의 크기를 가늠하는 값임.
- `낮음(이미 검색됨)`: 순위 1~3위. 사전 없이도 검색됨.
- `중간`: 4~50위.
- `큼`: 51위 이하. 사전이 있어야 찾을 수 있음.
- 정확 문자열 일치로 조회하는 경우에는 `낮음`도 가치가 있으므로 조회 방식에 따라 판단해야 함.

### 3.5 검토상태
- `사람확정`: 사람이 관계를 직접 판정한 건 (908건). `관계`는 사람 판정값임.
- `GPT판정(미검토)`: GPT 판정 그대로이며 사람이 보지 않음 (998건, 전부 일상어 검색 순위 1~3위 항목).

### 3.6 신뢰도
- `높음`: 사람확정 (908건).
- `중간`: 미검토이며 v3와 v5의 판정이 같은 계열(같음/하위 등)임 (998건). 순위 1~3위 표본 검증에서 사전 적합 약 82%였음 (5.9절).
- `낮음`: 미검토이며 v3와 v5의 판정이 다른 경우임. v1.2의 263건이 3차 검토에서 전수 검토되어 **v1.3에는 해당 항목이 없음**. 컬럼 값 체계와 조회 모듈 옵션은 향후 버전을 위해 유지함.
- 근거: 순위 4위 이하의 신뢰도별 정밀도는 5.5~5.6절, 순위 1~3위는 5.9절 참조.

## 4. 사전 포함 기준

사전에는 다음을 모두 만족하는 후보만 포함함.
1. 최종 관계가 동의, 약어·속어, 하위 중 하나임 (사람 라벨이 있으면 사람 판정 기준).
2. 충돌 정책상 다른 공식어에 귀속되지 않음 (`비귀속` 아님).
3. 다른 공식어와 일치하는 후보(공식어간 관계)가 아님.
4. 사람이 `판단불가`로 표시하지 않음.

같은 (정규화키, 공식어)가 중복이면 사람확정, 매칭강도 강, 낮은 순위 순으로 하나만 남김.

### 5.2 사람 검토 결과 (표본 519건)
GPT 프롬프트 **v3** 판정이 사람 판정과 얼마나 일치했는지 본 값임. 이 결과를 바탕으로 프롬프트를 v5로 수정함.

| 검토 시트 | 대상 | 사람도 같은 판정 |
|---|---|---|
| 검토1 | GPT가 같음(동의·약어·속어)으로 본 것 중 순위 4~50위 237건 | 152건 (64%, 95% 구간 58~70%) |
| 검토2 | GPT가 하위로 본 것 중 순위 51위 이하 252건 | 168건 (67%, 95% 구간 61~72%) |
| 검토3 | GPT가 무관으로 본 것 중 무작위 30건 | 무관 5건, 같음 11건, 관련 12건, 판단불가 2건 |

- 사람은 범위·조건 차이에 더 엄격함. 예: 공식어의 분류 구분(`~별`)이 후보에 빠진 경우, 제도 범위가 엄밀히 다른 관용 표현, 개별 시설·명소를 하위로 본 경우는 관련으로 판정함.
- GPT가 무관으로 본 후보 중 약 3분의 1(11/30)이 실제로는 같은 의미(오탈자, 비통용 표현, 어순 차이)였음. v3에서는 무관 판정이 많았고(212건), 이를 v5에서 재판정함.

### 5.3 프롬프트 v5 개선 효과 (같은 519건 재판정, 개발셋)
v5는 사람 라벨을 참고해 만든 프롬프트이므로 이 수치는 **낙관적**이며, 새 표본에서는 더 낮을 수 있음.

| 지표 | v3 | v5 |
|---|---|---|
| 5분류 일치율 (사람 판단불가 제외 510건) | 64% (325) | 70% (355) |
| GPT가 같음으로 본 것 중 사람도 같음 | 64% | 68% (234건 중 159건) |
| GPT가 하위로 본 것 중 사람도 하위 (표본 구성이 달라 완전한 동일 기준은 아님) | 약 67% | 73% (210건 중 154건) |
| 검토3(v3 무관 샘플) 일치율 | 18% | 61% |
| 사람이 같음으로 본 11건 중 GPT가 같음으로 회수 | 0 | 9 |

- 주요 변경: 오탈자, 어순, 비통용 표현도 뜻이 같으면 동의로 판정함. 공식어의 분류 구분(`~별`)이 후보에 없으면 관련으로 판정함. 기간, 표본조사, 말잔/평잔 같은 시점·집계방식 조건은 무시함. 개별 시설·명소·연상어는 하위가 아니라 관련으로 판정함.

## 6. 조회 방법

### 6.1 JSON 구조
```json
{
  "meta": {"version": "v1.3", "사전 항목": 1906, "고유 일상어(정규화키)": 1869,
           "판정프롬프트": "v5", "생성일": "2026-10-22"},
  "entries": {
    "주담대": [
      {"ID": "D01509", "일상어": "주담대", "공식어": "주택담보대출", "유형": "항목값",
       "관계": "약어·속어", "매칭강도": "강", "신뢰도": "중간", "모호어": "Y", "연결구분": "귀속",
       "귀속공식어": "주택담보대출", "역방향순위": "1", "검색보강": "낮음(이미 검색됨)",
       "서술형": "", "검토상태": "GPT판정(미검토)", "판정일치": "일치", "GPT관계": "약어·속어", "버전": "v1.3"}
    ]
  }
}
```
- 키는 `정규화키`이며 값은 항목 리스트임 (같은 키가 여러 공식어에 걸릴 수 있음).

### 6.2 Python 사용 (`stat_dictionary.py`)
```python
from stat_dictionary import StatDict, norm_term

d = StatDict.load("통계어사전_v1.3.json")

d.lookup("주담대")                        # 정규화키 정확 일치
d.expand("주담대 금리 추이 알려줘")          # 질문 속 일상어를 최장일치로 탐색
d.expand("주담대 금리", min_strength="강")   # 하위 근사 제외, 동의·약어·속어만
d.expand("주담대 금리", min_trust="높음")    # 사람확정 항목만 사용 (기본값은 전체)
```
- `expand` 결과 항목: `일상어`, `위치`, `공식어들`, `모호어`(bool), `항목`(원본 목록).
- 겹치는 일치는 긴 것만 채택하고, 키 길이 2 미만은 무시함 (`min_len` 조정 가능).

### 6.3 활용 권장 (제안)
- `강`: 질문의 일상어를 공식어로 바꿔 검색해도 같은 통계임. 공식어를 검색어에 추가하거나 치환 후보로 사용함.
- `중`(하위 근사): 공식어의 일부를 가리키므로 **치환하지 말고 확장 후보로만** 추가함.
- `모호어`가 `Y`이거나 `공식어들`이 둘 이상이면 단정하지 말고 복수 후보 또는 되묻기로 처리함.
- 사람확정 건을 우선하고, 미검토 건은 가중치를 낮추는 방식을 고려할 수 있음. 미검토 998건은 표본 검증에서 사전 적합 약 82%였으므로 기본 확장에 포함해도 되나, 정밀도를 우선하면 `min_trust="높음"`으로 사람확정만 쓸 수 있음.

## 7. 유의사항

1. **짧은 키의 오탐**: 부분 문자열 탐색이라 짧은 일상어가 공식어 내부에서 잡힐 수 있음 (예: `한은`이 `한은금융망` 안에서 일치). 3글자 이상으로 제한하거나 질문 속 공식어 구간을 제외하는 보완이 필요함.
2. 상위어와 관련어는 사전에 없음. 일상어가 넓은 개념(예: `예금`)이면 이 사전으로는 확장되지 않음.
3. 영문 표기, 오탈자 등 비통용 표현은 정규화키가 달라 정확 일치로는 조회되지 않음. 임베딩 조회와 병행할지는 팀 결정이 필요함.
4. 사람 판정 방향 기준은 일상어 기준임 (일상어가 공식어보다 좁으면 하위).
5. 판정은 GPT 프롬프트 v5 기준이며 미검토 항목이 998건 남아 있음(모두 순위 1~3위, 신뢰도 `중간`). 이 중 같음(강) 671건의 약 13%는 사람이 상위·관련으로 보았음(표본 60건 중 8건, 5.9절). 같음 판정은 신뢰도가 `낮음`이었던 경우 사람이 상위·관련으로 보는 비율이 훨씬 높았음(순위 4위 이하 기준 58%, 순위 1~3위 기준 67%).
6. 하위(근사)는 순위 4위 이하 새 표본에서 95%, 순위 1~3위 `중간` 표본에서 68%(관계 일치)였음. 공식어를 치환하는 용도가 아니라 확장 후보로만 사용할 것.

|---|---|
| `공식어` | 사전 CSV의 `공식어`와 동일하게 |
| `일상어후보` | 사전 CSV의 `일상어`와 동일하게 |
| `사람판정` | 동의, 약어·속어, 상위, 하위, 관련, 무관, 판단불가 중 하나 |

- 키는 `ID`가 아니라 **(공식어, 일상어후보)** 쌍임.
- 사람 판정이 있으면 GPT 판정을 덮어쓰며, `검토상태`는 `사람확정`이 됨.
- 사람이 관련·상위·무관으로 판정하면 사전에서 빠져 보류 목록으로 이동함.

### 8.3 재생성 명령 (관리자용)
```powershell
python kosis_dict_build.py --src 판정_gpt_v5_전체.csv --labels 사람판정_취합_519.csv 팀검토라벨_2차.csv 팀검토라벨_3차.csv `
  --prev-judged 판정_gpt_전체_수정.csv --outdir 통계어사전_v1.3 --version v1.3 --judge-ver v5
```
- `--labels`에는 여러 파일을 줄 수 있으며, 뒤에 적은 파일이 우선함.
