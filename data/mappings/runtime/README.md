# 실행용 용어 매핑 사전

기본 실행 사전이다. 현재 적용 범위와 한계는 [사전 검수 안내](../../../docs/guides/용어_매핑_작성과_검수.md)를 따른다.

- [search_mappings.json](search_mappings.json): v2 실행용 기준본, 매핑 79건·개념 69개
- [schema.json](schema.json): 파일 계약
- [review_queue.json](review_queue.json): 공식 근거·조건 구조화와 사람 검수 대기 목록
- [기존 검토 자료](../review/검색용_의미매핑_초안.json): 변경하지 않은 원천 76건; 후보 CSV 136행·우선순위 CSV 5,887행도 원천으로 보존

**현재 79건 모두 draft, approved 0건이다. reviewer는 전부 null이며 실제 사람 검수를 수행했다고 기록하지 않는다.** 운영 기본 정책은 approved만 소비하므로 현재 운영 확장은 0건이다. 평가 전용 draft_experiment는 효과·오류 확인용이며 승인 상태를 바꾸지 않는다. 초기 실험에서 명목 편향을 확인해 M007의 주개념을 국내총생산으로 수정했지만 여전히 초안이다.

표현을 개념과 연결하고 개념의 표명·경로·항목·주석 인용을 공식 보관 자료와 대조한다. 단순 문자열 출현은 동의어 관계나 해당 표의 질문 적합성을 보증하지 않는다. 정의·관련 개념·모호 표현은 자동 동의어 확장에서 제외한다.

conditions의 각 any_positive 목록 내부는 OR이며 여러 조건 간에는 AND를 적용한다. exclusions는 충돌 여부를 검사한다. 조건 누락·불명·부정·출처 불일치·범위 충돌은 trace에 보류 사유를 남긴다. unresolved 조건은 자연어 원문을 보존하고 확장하지 않는다. 조건 판정은 제한된 규칙이므로 사람의 의미 검수가 필요하다.

승인 시에는 표현과 공식 개념의 의미, 적용/제외 조건, 범위, 실제 인용과 판본을 확인하고 실제 검수자만 기록한다. 근거 부족 매핑에 승인 표시만 붙여 우회하지 않는다. 모델 제안도 draft로만 수집한다. 검수 큐는 승인 데이터가 아니다.

재생성은 저장소 루트에서 **새 출력 폴더**로 수행한다.

```powershell
uv run --locked python scripts/prepare_mapping_dictionary.py --output eval/results/mapping-rebuild/dictionary
```

생성기는 기존 JSON·CSV와 공식 목록/메타만 사용하며 평가 질문·정답은 읽지 않는다. 이미 사람이 검수한 기준본을 생성기 출력으로 덮어쓰지 말고 변경 내용을 대조해 반영한다. 실행용 파일이 유일한 소비 기준이며 review 원천은 별개의 승인 사전이 아니다.
